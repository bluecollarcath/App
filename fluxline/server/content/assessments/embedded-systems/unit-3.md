Covers Lessons 3.1–3.3: serial buses, real-time operating systems, and low-power design.

```quiz
? A UART at 57,600 baud uses 8N1 framing. How many bytes per second can it carry?
= 5760 | 0.001 |
> 10 bits per byte.
```

```quiz
? An SPI bus runs at 4 MHz. How many bytes per second can it move?
= 500000 | 0.001 |
> $4\times10^6/8$.
```

```quiz
? Three periodic tasks have $(C, T)$ = (1, 5), (2, 8) and (4, 20) ms. What is their utilization?
= 0.65 | 0.001 |
> $0.2 + 0.25 + 0.2$.
```

```quiz
? What is the rate-monotonic utilization bound for 2 tasks?
= 0.8284 | 0.002 |
> $2(\sqrt2 - 1)$.
```

```quiz
? A node draws 20 mA for 5 ms per second and 5 µA otherwise. What is its average current, in µA?
= 104.98 | 0.005 | µA
> $20000(0.005) + 5(0.995)$.
```

```quiz
? On a 1000 mAh battery, how many days does that node last?
= 396.9 | 0.005 | days
> $1000/0.10498 = 9526$ h.
```

```quiz
? I²C uses pull-up resistors because:
+ its lines are open-drain, so devices can only pull them low
- it is a full-duplex bus
- it has no ground connection
- its clock is generated by the target
> The resistors provide the high level.
```

```quiz
? A high-priority task waits on a mutex held by a low-priority task, which keeps being preempted by a medium-priority task. This is:
```
