Covers Lessons 3.1–3.3: Laplace transforms, inverse transforms, and steps, impulses and convolution.

```quiz
? What is $\mathcal L\{5\cos3t\}$ evaluated at $s = 4$?
= 0.8 | 0.001 |
> $5s/(s^2 + 9) = 20/25$.
```

```quiz
? $y' + 3y = 0$ with $y(0) = 6$. What is $Y(s)$ at $s = 0$?
= 2 | 0.001 |
> $Y = 6/(s + 3)$.
```

```quiz
? $F(s) = \dfrac{12}{s(s + 4)}$. What is $f(\infty)$?
= 3 | 0.001 |
> $\lim_{s\to0}12/(s + 4)$.
```

```quiz
? $Y = \dfrac{2s + 5}{(s + 1)(s + 3)}$. What is the residue at $s = -1$?
= 1.5 | 0.001 |
> $(-2 + 5)/(-1 + 3)$.
```

```quiz
? $Y = \dfrac{1}{(s + 2)^2}$. What is $y(0.5)$?
= 0.1839 | 0.002 |
> $te^{-2t}$: $0.5e^{-1}$.
```

```quiz
? A system has $H(s) = \dfrac{6}{s + 3}$. What is its impulse response at $t = 0$?
= 6 | 0.001 |
> $h = 6e^{-3t}$.
```
