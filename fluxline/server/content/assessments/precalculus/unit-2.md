Covers Lessons 2.1–2.4: functions and graphs, domain and range, slope and lines, systems of linear equations, and transforming, composing and inverting functions.

```quiz
? Let $f(x) = 3x^2 - 2x$. What is $f(-1)$?
= 5 | 0.001 |
> $3(-1)^2 - 2(-1) = 3 + 2 = 5$.
```

```quiz
? What is the domain of $f(x) = \dfrac{1}{x - 2}$?
+ every number except $2$
- every number except $0$
- $x \ge 2$
- every number
> You can't divide by zero, and $x - 2 = 0$ when $x = 2$.
```

```quiz
? What is the slope of the line through $(-1, 4)$ and $(3, -4)$?
= -2 | 0.001 |
> $\dfrac{-4 - 4}{3 - (-1)} = \dfrac{-8}{4} = -2$.
```

```quiz
? A line has slope 3 and passes through $(2, 5)$. What is $y$ when $x = 4$?
= 11 | 0.001 |
> $5 = 3(2) + b$ gives $b = -1$, so $y = 3x - 1 = 11$ at $x = 4$.
```

```quiz
? A battery's voltage falls steadily from 12.6 V at $t = 0$ to 11.4 V at $t = 6$ hours. What is the rate of change, in V/h?
= -0.2 | 0.001 | V/h
> $\dfrac{11.4 - 12.6}{6 - 0} = \dfrac{-1.2}{6} = -0.2$ V/h. Negative because it's falling.
```

```quiz
? Solve $x + 2y = 8$ and $3x - 2y = 8$. What is $y$?
= 2 | 0.001 |
> Add the equations: $4x = 16$, so $x = 4$; then $4 + 2y = 8$, so $y = 2$.
```

```quiz
? Solve $y = 3x - 1$ and $2x + y = 9$. What is $y$?
= 5 | 0.001 |
> Substitute: $2x + 3x - 1 = 9$, so $x = 2$ and $y = 5$.
```

```quiz
? Compared with $y = x^2$, the graph of $y = x^2 - 5$ is:
+ shifted down 5
- shifted up 5
- shifted right 5
- shifted left 5
> Subtracting outside the function moves every output down by 5.
```

```quiz
? Let $f(x) = x + 1$ and $g(x) = 2x$. What is $g(f(3))$?
= 8 | 0.001 |
> $f(3) = 4$, then $g(4) = 8$.
```

```quiz
? If $f(x) = \dfrac{x - 4}{3}$, what is $f^{-1}(2)$?
= 10 | 0.001 |
> Solve $y = \dfrac{x - 4}{3}$ for $x$: $f^{-1}(x) = 3x + 4$, so $f^{-1}(2) = 10$. Check: $f(10) = 2$.
```
