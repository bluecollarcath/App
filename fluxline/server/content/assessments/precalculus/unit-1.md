Covers Lessons 1.1–1.4: negative numbers, order of operations, fractions and percentages; exponents, roots, scientific notation and engineering prefixes; solving equations and rearranging formulas; factoring and quadratic equations. Fractions like 11/10 are accepted as answers.

```quiz
? What is $9 - (-4)$?
= 13 | 0.001 |
> Subtracting a negative adds: $9 + 4 = 13$.
```

```quiz
? What is $(-2)^3$?
= -8 | 0.001 |
> $(-2)(-2)(-2) = 4 \times (-2) = -8$.
```

```quiz
? What is $24 \div 4 \times 3 - 2^2$?
= 14 | 0.001 |
> Exponent first: $2^2 = 4$. Then left to right: $24 \div 4 = 6$, $6 \times 3 = 18$. Finally $18 - 4 = 14$.
```

```quiz
? What is $\dfrac{3}{5} + \dfrac{1}{2}$?
= 1.1 | 0.001 |
> Common denominator 10: $\dfrac{6}{10} + \dfrac{5}{10} = \dfrac{11}{10} = 1.1$.
```

```quiz
? What is $\dfrac{2}{3} \times \dfrac{9}{4}$?
= 1.5 | 0.001 |
> $\dfrac{2 \times 9}{3 \times 4} = \dfrac{18}{12} = 1.5$.
```

```quiz
? What is $2^{-2} \times 2^5$?
= 8 | 0.001 |
> Add the exponents: $2^{-2+5} = 2^3 = 8$.
```

```quiz
? In scientific notation, $0.0036 = 3.6 \times 10^{?}$. What is the exponent?
= -3 | 0.001 |
> The decimal point moves 3 places right to get 3.6.
```

```quiz
? How many milliamps is 47 µA?
= 0.047 | 0.001 | mA
> micro to milli is one step of 1000: $47 \div 1000 = 0.047$ mA.
```

```quiz
? Solve $4x - 7 = 2x + 5$.
= 6 | 0.001 |
> Subtract $2x$: $2x - 7 = 5$. Add 7: $2x = 12$. So $x = 6$.
```

```quiz
? A resistor of $R = 50\ \Omega$ dissipates $P = 0.5$ W. Using $P = I^2R$, what current flows, in A?
= 0.1 | 0.001 | A
> $I = \sqrt{P/R} = \sqrt{0.01} = 0.1$ A.
```

```quiz
? Which is equal to $(x - 3)^2$?
+ $x^2 - 6x + 9$
- $x^2 - 9$
- $x^2 + 9$
- $x^2 - 3x + 9$
> $(x - 3)(x - 3) = x^2 - 3x - 3x + 9 = x^2 - 6x + 9$.
```

```quiz
? Solve $x^2 - 2x - 15 = 0$. What is the **larger** solution?
= 5 | 0.001 |
> Factor: $(x - 5)(x + 3) = 0$, so $x = 5$ or $x = -3$.
```

```quiz
? Solve $3x^2 - 5x - 2 = 0$. What is the **positive** solution?
= 2 | 0.001 |
> $b^2 - 4ac = 25 + 24 = 49$, so $x = \dfrac{5 \pm 7}{6}$: $2$ or $-\tfrac{1}{3}$.
```
