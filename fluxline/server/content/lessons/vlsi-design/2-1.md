## How fast is a gate?

A gate's delay comes from charging and discharging capacitance through transistor resistance. Model a unit-size inverter as a resistance $R$ driving its load; its delay is proportional to $RC$. Scaling a gate up by a factor $k$ divides its resistance by $k$ and multiplies its input capacitance by $k$. **Logical effort** (Sutherland, Sproull and Harris) turns this into a simple, powerful method for sizing gates along a path.

## Delay of a single gate

Measured in units of $\tau$ (the delay of an ideal inverter driving an identical inverter, without parasitics), each gate's delay is

$$
d = gh + p
$$

- **Electrical effort** $h = C_{out}/C_{in}$: how much bigger the load is than the gate's own input capacitance.
- **Logical effort** $g$: how much worse the gate is at driving current than an inverter with the same input capacitance. From the sizing in Lesson 1.2: inverter 1, NAND2 $4/3$, NOR2 $5/3$, NAND3 $5/3$, NOR3 $7/3$.
- **Parasitic delay** $p$: the gate's own diffusion capacitance; about 1 for an inverter, about $n$ for an $n$-input NAND or NOR.

The product $f = gh$ is the **stage effort**.

## Optimizing a path

For a path of $N$ stages, define:

- path logical effort $G = \prod g_i$,
- path electrical effort $H = C_{out,path}/C_{in,path}$,
- branching effort $B = \prod b_i$ (extra load from fan-out to other branches),
- **path effort** $F = GBH$.

The delay is minimized when **every stage bears the same effort**:

$$
\hat f = F^{1/N}, \qquad D_{min} = N F^{1/N} + \sum p_i
$$

Then size the gates backward from the output: each gate's input capacitance is $C_{in,i} = g_iC_{out,i}/\hat f$.

The best number of stages makes $\hat f$ about **4** (between 2.7 and 6 is nearly as good), so

$$
N_{opt} \approx \log_4F
$$

> **Example 1.** A unit inverter must drive a load 64 times its input capacitance. $F = 64$, so the best path has $\log_464 = 3$ inverters, each with effort 4 (sizes 1, 4, 16): $D = 3(4) + 3(1) = 15\tau$. One inverter alone would take $64 + 1 = 65\tau$.

> **Example 2.** A NAND2 followed by an inverter drives a load 10 times the NAND's input: $G = 4/3$, $H = 10$, $F = 13.3$. With 2 stages, $\hat f = \sqrt{13.3} = 3.65$, and $D = 2(3.65) + (2 + 1) = 10.3\tau$.

## What logical effort teaches

- Big loads (off-chip pins, long wires, wide buses, clock nets) need a chain of **gradually** increasing buffers, not one giant one.
- Multi-input gates are expensive: high-fan-in NORs especially. Restructure logic into trees of smaller gates when the path effort is large.
- Adding an inverter (a stage) can **reduce** delay when the stage effort is far above 4.

Synthesis tools perform exactly this kind of sizing automatically when they map logic to standard cells (Lesson 3.3).

## Key takeaways

- Gate delay $d = gh + p$ (in $\tau$): logical effort $g$, electrical effort $h$, parasitic $p$.
- Path effort $F = GBH$; minimum delay $NF^{1/N} + \sum p$ with equal stage effort.
- Best stage effort is about 4, so $N \approx \log_4F$; buffer chains grow geometrically.
