## Turning calculus into algebra

The **Laplace transform** converts a differential equation in time into an algebraic equation in a complex variable $s$, including its initial conditions. Solve the algebra, transform back, and you have the complete response in one pass.

$$
F(s) = \mathcal L\{f(t)\} = \int_0^\infty f(t)\,e^{-st}\,dt
$$

(an improper integral, Calculus Lesson 2.4; it converges for $\text{Re}\,s$ large enough).

## Transform pairs

| $f(t)$, for $t \ge 0$ | $F(s)$ |
|---|---|
| $\delta(t)$ (impulse) | $1$ |
| $1$ (unit step) | $\dfrac1s$ |
| $t$ | $\dfrac{1}{s^2}$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ |
| $e^{-at}$ | $\dfrac{1}{s + a}$ |
| $te^{-at}$ | $\dfrac{1}{(s + a)^2}$ |
| $\sin\omega t$ | $\dfrac{\omega}{s^2 + \omega^2}$ |
| $\cos\omega t$ | $\dfrac{s}{s^2 + \omega^2}$ |
| $e^{-at}\sin\omega t$ | $\dfrac{\omega}{(s + a)^2 + \omega^2}$ |
| $e^{-at}\cos\omega t$ | $\dfrac{s + a}{(s + a)^2 + \omega^2}$ |

## Properties

| Property | Time domain | $s$ domain |
|---|---|---|
| Linearity | $af + bg$ | $aF + bG$ |
| **Derivative** | $f'(t)$ | $sF(s) - f(0)$ |
| Second derivative | $f''(t)$ | $s^2F - sf(0) - f'(0)$ |
| Integral | $\int_0^tf\,d\tau$ | $F(s)/s$ |
| Frequency shift | $e^{-at}f(t)$ | $F(s + a)$ |
| **Time delay** | $f(t - T)u(t - T)$ | $e^{-sT}F(s)$ |

The derivative property is the key: differentiation becomes multiplication by $s$, with the **initial condition built in**.

## Solving an ODE

> $y' + 2y = 4$, $y(0) = 0$. Transform each term:
> $$sY(s) - 0 + 2Y(s) = \frac4s \quad\Rightarrow\quad Y(s) = \frac{4}{s(s + 2)}$$
> Partial fractions (next lesson): $Y = \dfrac2s - \dfrac{2}{s + 2}$, so $y(t) = 2 - 2e^{-2t}$.

> With a nonzero initial condition, $y(0) = 5$: $sY - 5 + 2Y = 4/s$, so $Y = \dfrac{4}{s(s + 2)} + \dfrac{5}{s + 2}$. The two terms are the forced and the initial-condition (natural) responses, automatically separated.

## Initial and final value theorems

Read limits straight from $F(s)$ without inverting:

$$
f(0^+) = \lim_{s\to\infty}sF(s), \qquad f(\infty) = \lim_{s\to0}sF(s)
$$

The final value theorem is valid only if $f$ actually settles: all poles of $sF(s)$ in the left half-plane.

> For $Y = \dfrac{4}{s(s + 2)}$: $y(\infty) = \lim_{s\to0}\dfrac{4}{s + 2} = 2$. ✓

This is how control engineers find steady-state errors (Control Systems, Lesson 2.3).

## Key takeaways

- $F(s) = \int_0^\infty f(t)e^{-st}dt$; memorize the basic pairs (step, exponential, sinusoids).
- Derivatives become $sF - f(0)$: ODEs with initial conditions become algebra.
- Shifts: $e^{-at}f \leftrightarrow F(s + a)$; delay $\leftrightarrow e^{-sT}F$.
- Initial and final value theorems read limits directly from $F(s)$.
