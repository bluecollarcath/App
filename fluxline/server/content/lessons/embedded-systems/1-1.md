## The contract between hardware and software

The **instruction set architecture (ISA)** is the interface a processor presents to software: its registers, instructions, data types, addressing modes, and memory model. Compilers target the ISA; hardware designers implement it. Many different microarchitectures can implement one ISA (an ARM Cortex-M0 and an Apple M-series both run ARM code).

## RISC vs. CISC

| | RISC (ARM, RISC-V) | CISC (x86) |
|---|---|---|
| Instructions | simple, fixed length | complex, variable length |
| Memory access | **load/store only** | most instructions can touch memory |
| Registers | many (16–32) | historically fewer |
| Decoding | simple, easy to pipeline | complex (translated to micro-ops internally) |

Virtually all embedded processors are RISC. In a **load/store architecture**, arithmetic operates only on registers; data moves between registers and memory with explicit load and store instructions.

## A taste of RISC-V assembly

Compute `a = b + c - 5`, with `b` and `c` in memory:

```asm
    lw   t0, 0(a1)      # t0 = b   (load word from address in a1)
    lw   t1, 4(a1)      # t1 = c
    add  t2, t0, t1     # t2 = b + c
    addi t2, t2, -5     # t2 = t2 - 5
    sw   t2, 8(a1)      # a = t2   (store word)
```

Five instructions, three of them memory operations — memory access is usually the bottleneck.

## Measuring performance

The **iron law** of processor performance:

$$
\text{CPU time} = \text{Instruction count} \times \text{CPI} \times \frac{1}{f_{clk}}
$$

ISA design trades instruction count against CPI (cycles per instruction) and achievable clock frequency. RISC accepts more instructions in exchange for low CPI and fast clocks.

## Address space

An $n$-bit address can name $2^n$ bytes. A 32-bit microcontroller has a 4 GiB address space — far more than its actual memory — so peripherals are mapped into unused addresses (**memory-mapped I/O**). Writing to address `0x40020014` might turn on an LED. That's the subject of Unit 2.

## Practice

```quiz
? A program executes $10^9$ instructions with an average CPI of 1.5 on a 1 GHz processor. How long does it take, in seconds?
= 1.5 | 0.01 | s
> $10^9 \times 1.5 / 10^9 = 1.5$ s.
```

```quiz
? How many bytes can a 16-bit address bus address?
= 65536 | 0 | bytes
> $2^{16} = 65{,}536$ bytes (64 KiB).
```


## Key takeaways

- The ISA is the hardware/software contract.
- Embedded processors are RISC load/store machines.
- CPU time = IC × CPI / f.
