## Counting clock cycles

A **timer** is a counter that increments on each tick of a (divided) clock. Because it runs in hardware, it measures and generates time precisely, independent of what the software is doing. Timers produce periodic interrupts (the "tick" of an operating system), measure pulse widths and frequencies, and generate **PWM** signals for motors, LEDs and power converters.

## Prescaler and period

A typical timer has two settings:

- the **prescaler** (PSC) divides the input clock: $f_{tick} = f_{clk}/(\text{PSC} + 1)$;
- the **auto-reload** value (ARR) sets where the counter wraps back to 0, so the timer's period is $(\text{ARR} + 1)$ ticks.

$$
f_{overflow} = \frac{f_{clk}}{(\text{PSC} + 1)(\text{ARR} + 1)}
$$

> **Example.** A 72 MHz clock with PSC = 71 gives 1 MHz ticks (1 µs each). ARR = 999 makes the counter wrap every 1000 µs: a 1 kHz interrupt.

The "+1"s are a classic source of off-by-one errors: a register value of $N$ divides by $N + 1$.

## Compare and PWM

A **compare** channel holds a value CCR. In PWM mode, the output is high while the counter is below CCR and low after:

$$
\text{duty cycle} = \frac{\text{CCR}}{\text{ARR} + 1}
$$

With ARR = 999 (1 kHz) and CCR = 250, the output is high 25% of each period.

```plot
x: 0, 3, time (ms)
y: -0.3, 3.8, voltage (V)
f: 3.3*(1 - u(mod(x, 1) - 0.25)) | PWM output, 25% duty
hline: 0.825
caption: A 1 kHz PWM signal at 25% duty cycle. Averaged (by a motor's inertia, an LED as seen by the eye, or an RC filter) it acts like $0.25 \times 3.3 = 0.83$ V.
```

PWM is how microcontrollers make "analog" outputs with only digital pins: the load or a filter averages the waveform. LED dimming, DC motor speed control, servo positioning, class-D audio and every switching power supply use it.

**Resolution vs. frequency.** The duty cycle can only take ARR + 1 different values, so with an unprescaled clock

$$
\text{resolution (bits)} = \log_2\frac{f_{clk}}{f_{PWM}}
$$

A 72 MHz clock gives $\log_2(72\times10^6/20\times10^3) = 11.8$ bits at 20 kHz (above hearing, common for motors), but only 6.2 bits at 1 MHz. Faster PWM means coarser steps.

> **Hobby servos** expect a 50 Hz signal whose high time sets the angle: 1.0 ms for one end, 1.5 ms for center, 2.0 ms for the other end.

## Input capture

The reverse operation: on an input edge, the timer **captures** the current count into a register. Subtracting consecutive captures gives a period or pulse width with one-tick precision, used for reading encoders, ultrasonic range finders, RPM sensors and IR remote codes.

## Key takeaways

- $f_{overflow} = f_{clk}/[(\text{PSC} + 1)(\text{ARR} + 1)]$; watch the off-by-one.
- PWM duty $= \text{CCR}/(\text{ARR} + 1)$; averaged, it acts as an analog level.
- Resolution $= \log_2(f_{clk}/f_{PWM})$ bits: faster PWM, coarser steps.
- Input capture timestamps edges to measure periods and pulse widths.
