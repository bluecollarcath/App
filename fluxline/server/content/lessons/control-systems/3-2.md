## Shaping the response

If no gain on the root locus gives the response you need, you add **dynamics** to the controller. The workhorse is the **PID controller**, used in the vast majority of industrial loops: temperature, pressure, motor speed, drone attitude.

$$
u(t) = K_p\,e(t) + K_i\int_0^t e(\tau)\,d\tau + K_d\,\frac{de}{dt}
\qquad\Longleftrightarrow\qquad
C(s) = K_p + \frac{K_i}{s} + K_d s
$$

## What each term does

| Term | Responds to | Main effect | Side effect |
|---|---|---|---|
| **P** $K_p$ | present error | faster response, smaller error | more overshoot; leaves error in type-0 loops |
| **I** $K_i/s$ | accumulated past error | **zero steady-state error** (raises system type) | slower, more overshoot, can wind up |
| **D** $K_ds$ | rate of change (predicts) | **adds damping**, less overshoot | amplifies sensor noise |

> **Example: P vs. PI.** The plant is $G(s) = 1/(s + 1)$.
>
> - **P only, $K_p = 9$:** $T = \dfrac{9}{s + 10}$. Fast ($\tau = 0.1$ s) but it settles at 0.9: a 10% error that only more gain can shrink.
> - **PI, $K_p = 9$, $K_i = 25$:** $C = \dfrac{9s + 25}{s}$ and
> $$T(s) = \frac{9s + 25}{s^2 + 10s + 25} = \frac{9s + 25}{(s + 5)^2}$$
> The step response is $y(t) = 1 - e^{-5t} + 4t\,e^{-5t}$. It reaches **exactly 1**, with a small 8.4% overshoot at $t = 0.45$ s caused by the controller's zero at $s = -25/9$.

## Tuning: Ziegler–Nichols

A classic recipe that needs no model: turn off I and D, raise $K_p$ until the loop **just** oscillates steadily. Record that **ultimate gain** $K_u$ and the oscillation period $T_u$, then set

| Controller | $K_p$ | $T_i$ | $T_d$ |
|---|---|---|---|
| P | $0.5K_u$ | | |
| PI | $0.45K_u$ | $T_u/1.2$ | |
| PID | $0.6K_u$ | $T_u/2$ | $T_u/8$ |

with $K_i = K_p/T_i$ and $K_d = K_pT_d$.

> **Example.** For $G = 1/[s(s + 2)(s + 4)]$ the last lesson found $K_u = 48$ at $\omega_u = 2.83$ rad/s, so $T_u = 2\pi/2.83 = 2.22$ s. PID tuning gives $K_p = 28.8$, $T_i = 1.11$ s, $T_d = 0.278$ s, so $K_i = 25.9$ and $K_d = 8.0$.

Ziegler–Nichols settings are aggressive (often 25% or more overshoot). Treat them as a starting point and fine-tune.

## Lead and lag compensators

A first-order compensator puts one zero and one pole where you want them:

$$
C(s) = K_c\,\frac{s + z}{s + p}
$$

- **Lead** ($z < p$, zero closer to the origin): adds positive phase near the crossover. It pulls the root locus **left** for a faster, better-damped response. It is a practical, noise-limited version of PD.
- **Lag** ($z > p$, both near the origin): boosts low-frequency gain by $z/p$, cutting steady-state error by that factor while barely moving the dominant poles. It is a practical version of PI.

## Practical PID

- **Integrator windup.** If the actuator saturates (a valve fully open), the integral keeps growing and causes a big overshoot later. Clamp the integrator or stop integrating while the actuator is saturated (anti-windup).
- **Derivative filtering.** Pure $K_ds$ has unbounded gain at high frequency. Use $K_ds/(\tau_fs + 1)$ instead.
- **Derivative on measurement.** Differentiate $-y$ instead of $e$, so a step in the setpoint doesn't produce a huge spike ("derivative kick").

## Key takeaways

- P speeds things up, I removes steady-state error, D adds damping.
- Ziegler–Nichols: from $K_u$ and $T_u$, PID $K_p = 0.6K_u$, $T_i = T_u/2$, $T_d = T_u/8$.
- Lead adds phase and speed (like PD); lag adds low-frequency gain (like PI).
- In practice, add anti-windup and filter the derivative.
