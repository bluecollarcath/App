## How close is close enough?

After the transient dies out, does the output actually reach the setpoint? The **steady-state error** $e_{ss}$ is the difference that remains. For a unity-feedback system with open-loop transfer function $G(s)$, the final value theorem gives

$$
e_{ss} = \lim_{s\to0} \frac{s\,R(s)}{1 + G(s)}
$$

(valid only if the closed loop is stable, so check that first).

## System type

Write $G(s)$ with its poles at the origin pulled out:

$$
G(s) = \frac{K(1 + \tau_as)(1 + \tau_bs)\cdots}{s^N(1 + \tau_1s)(1 + \tau_2s)\cdots}
$$

The number of **integrators** $N$ is the **system type**. Each integrator lets the system track one more "order" of input with zero error, because an integrator keeps changing its output as long as any error remains.

## Error constants

| Input | Error constant | Type 0 | Type 1 | Type 2 |
|---|---|---|---|---|
| Step $R/s$ | $K_p = \lim_{s\to0} G(s)$ | $\dfrac{R}{1 + K_p}$ | 0 | 0 |
| Ramp $R/s^2$ | $K_v = \lim_{s\to0} sG(s)$ | $\infty$ | $\dfrac{R}{K_v}$ | 0 |
| Parabola $R/s^3$ | $K_a = \lim_{s\to0} s^2G(s)$ | $\infty$ | $\infty$ | $\dfrac{R}{K_a}$ |

> **Example 1 (type 0).** $G(s) = \dfrac{10}{(s + 1)(s + 2)}$: $K_p = G(0) = 5$, so a unit step leaves $e_{ss} = \frac{1}{1 + 5} = 0.167$, a 16.7% error.

> **Example 2 (type 1).** $G(s) = \dfrac{20}{s(s + 4)}$: zero error to a step; to a unit ramp, $K_v = 20/4 = 5$ and $e_{ss} = 0.2$. A cruise control of this type follows a steadily rising speed command, lagging it by a constant amount.

## Reducing steady-state error

- **Raise the gain:** the error falls, but overshoot rises and stability margins shrink (more next unit).
- **Add an integrator** (integral control, Lesson 3.2): raises the system type, eliminating the error for that input class. That's why nearly every industrial controller includes integral action.

## Key takeaways

- $e_{ss} = \lim_{s\to0} sR/(1 + G)$; check closed-loop stability first.
- System type = number of integrators in $G$; each one removes error for one more input order.
- $K_p$, $K_v$, $K_a$ give the finite errors for step, ramp, and parabola.
