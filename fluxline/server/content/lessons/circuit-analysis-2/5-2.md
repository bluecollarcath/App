## What filters do

A **filter** passes some frequencies and attenuates others. They're everywhere: anti-aliasing before an ADC, removing switching noise from a power supply, separating radio channels, the crossover in a loudspeaker. The four basic types:

| Type | Passes | Example $H(s)$ (first or second order) |
|---|---|---|
| Low-pass | below $\omega_c$ | $\dfrac{\omega_c}{s + \omega_c}$ |
| High-pass | above $\omega_c$ | $\dfrac{s}{s + \omega_c}$ |
| Band-pass | near $\omega_0$ | $\dfrac{(\omega_0/Q)s}{s^2 + (\omega_0/Q)s + \omega_0^2}$ |
| Band-stop (notch) | all but near $\omega_0$ | $\dfrac{s^2 + \omega_0^2}{s^2 + (\omega_0/Q)s + \omega_0^2}$ |

## Passive first-order filters

An RC divider with the output across the capacitor is a low-pass filter with cutoff (−3 dB) frequency

$$
\omega_c = \frac{1}{RC}, \qquad f_c = \frac{1}{2\pi RC}
$$

Swap R and C (output across R) for a high-pass filter with the same cutoff.

> **Design example.** Make a 1 kHz low-pass with a 10 nF capacitor.
> $R = \dfrac{1}{2\pi(1000)(10^{-8})} = 15.9$ kΩ. The nearest standard E24 value is 16 kΩ, giving $f_c = 995$ Hz.

## Resonant band-pass

A series RLC with the output across R passes frequencies near resonance:

$$
\omega_0 = \frac{1}{\sqrt{LC}}, \qquad B = \frac{R}{L}\ \text{(bandwidth, rad/s)}, \qquad Q = \frac{\omega_0}{B} = \frac{1}{R}\sqrt{\frac{L}{C}}
$$

Higher $Q$ means a narrower, more selective filter.

> $R = 10\ \Omega$, $L = 10$ mH, $C = 1\ \mu$F: $\omega_0 = 10^4$ rad/s (1.59 kHz), $B = 1000$ rad/s, $Q = 10$.

## Sharper filters: order and Butterworth

A first-order filter rolls off at only 20 dB/decade. An $n$th-order filter rolls off at $20n$ dB/decade. The **Butterworth** design gives the flattest possible passband:

$$
|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega/\omega_c)^{2n}}}
$$

```plot

y: -60, 5, |H| (dB)
f: -10*log10(1 + x^2) | n = 1
f: -10*log10(1 + x^4) | n = 2
f: -10*log10(1 + x^8) | n = 4
hline: -3.01, −3 dB
caption: Butterworth low-pass responses. All pass −3 dB at the cutoff; higher order means a steeper skirt.
```

Other families trade passband flatness for steepness (Chebyshev) or for constant time delay (Bessel).

## Active filters: the Sallen–Key low-pass

Passive second-order filters need inductors, which are bulky and imperfect at low frequencies. **Active filters** use op-amps, resistors, and capacitors instead. The unity-gain **Sallen–Key** low-pass:

```circuit
T 0,1 v_i
R 0,1 1.6,1 R_1 side=-1
R 1.6,1 3.2,1 R_2
W 3.2,1 4,1
C 3.2,1 3.2,2.4 C_2 side=-1
GND 3.2,2.4
C 1.6,1 1.6,-0.2 C_1
W 1.6,-0.2 6,-0.2
W 6,-0.2 6,1.5
OA 5,1.5 flip
W 4,2 4,2.7
W 4,2.7 6,2.7
W 6,2.7 6,1.5
W 6,1.5 7,1.5
T 7,1.5 v_o
caption: Unity-gain Sallen–Key low-pass. $C_1$ provides positive feedback that sharpens the corner.
```

$$
\omega_0 = \frac{1}{\sqrt{R_1R_2C_1C_2}}, \qquad Q = \frac{\sqrt{R_1R_2C_1C_2}}{C_2(R_1 + R_2)}
$$

With $R_1 = R_2 = R$: $Q = \tfrac12\sqrt{C_1/C_2}$. A second-order Butterworth needs $Q = 0.707$, so choose $C_1 = 2C_2$.

> $R = 10$ kΩ, $C_2 = 10$ nF, $C_1 = 20$ nF: $f_0 = \dfrac{1}{2\pi\sqrt{(10^4)^2(2\times10^{-16})}} = 1.13$ kHz, Butterworth response.

## Key takeaways

- First-order RC: $f_c = 1/(2\pi RC)$, 20 dB/decade.
- RLC band-pass: $\omega_0 = 1/\sqrt{LC}$, $B = R/L$, $Q = \omega_0/B$.
- $n$th order rolls off at $20n$ dB/dec; Butterworth is maximally flat.
- Sallen–Key: $\omega_0 = 1/\sqrt{R_1R_2C_1C_2}$; equal R and $C_1 = 2C_2$ gives Butterworth.
