## Three sources, one pattern

A **balanced three-phase source** is three sinusoidal voltages of equal magnitude, 120° apart. In positive (abc) sequence:

$$
\mathbf V_{an} = V_p\angle0^\circ, \quad
\mathbf V_{bn} = V_p\angle{-120^\circ}, \quad
\mathbf V_{cn} = V_p\angle{+120^\circ}, \qquad
\mathbf V_{an} + \mathbf V_{bn} + \mathbf V_{cn} = 0
$$

Sources and loads can each be connected in **wye (Y)**, with one end of each phase at a common neutral, or **delta (Δ)**, with the phases connected end-to-end in a loop.

## Line and phase quantities

**Phase** quantities are across or through one phase element; **line** quantities are between or on the lines.

| | Y connection | Δ connection |
|---|---|---|
| Voltage | $\mathbf V_{ab} = \sqrt3\,\mathbf V_{an}\angle30^\circ$, so $V_L = \sqrt3\,V_p$ | $V_L = V_p$ |
| Current | $I_L = I_p$ | $\mathbf I_a = \sqrt3\,\mathbf I_{AB}\angle{-30^\circ}$, so $I_L = \sqrt3\,I_p$ |

The $\sqrt3$ comes from subtracting two phasors 120° apart: $1\angle0^\circ - 1\angle{-120^\circ} = \sqrt3\angle30^\circ$.

A balanced Δ load converts to an equivalent Y load with $\mathbf Z_Y = \mathbf Z_\Delta/3$ (the same rule as resistive Δ–Y conversion).

## Per-phase analysis

In a balanced Y–Y system the neutral points are at the same potential (the neutral current is zero), so each phase is an independent circuit. Solve **phase a only**, then shift the results by ∓120° for phases b and c. Convert any Δ sources or loads to Y first.

```circuit
VAC 0,0 0,2 V_{an} side=-1
Z 0,0 2.4,0 Z_{line} i=I_a
Z 2.4,0 2.4,2 Z_{load}
W 2.4,2 0,2

```

> **Worked example.** A balanced Y–Y system has 208 V line-to-line, line impedance $1 + j2\ \Omega$, and load $20 + j10\ \Omega$ per phase.
>
> Phase voltage: $V_p = 208/\sqrt3 = 120$ V, so $\mathbf V_{an} = 120\angle0^\circ$ V.
>
> $$\mathbf I_a = \frac{120\angle0^\circ}{(1 + j2) + (20 + j10)} = \frac{120}{21 + j12} = 4.96\angle{-29.74^\circ}\ \text{A}$$
>
> Then $\mathbf I_b = 4.96\angle{-149.74^\circ}$ A and $\mathbf I_c = 4.96\angle{90.26^\circ}$ A.
>
> Load phase voltage: $\mathbf V_{AN} = \mathbf I_a(20 + j10) = 110.9\angle{-3.18^\circ}$ V, so the load sees only $\sqrt3 \times 110.9 = 192$ V line-to-line, an 8% drop.
>
> Power to the load: $P = 3\,|I_a|^2(20) = 1477$ W. Power lost in the lines: $3\,|I_a|^2(1) = 73.8$ W.

## Power in balanced systems

$$
P = 3V_pI_p\cos\theta = \sqrt3\,V_LI_L\cos\theta, \qquad
Q = \sqrt3\,V_LI_L\sin\theta, \qquad
|\mathbf S| = \sqrt3\,V_LI_L
$$

where $\theta$ is the angle of the **load impedance** per phase. Unlike single-phase power, the total instantaneous three-phase power is **constant**, with no double-frequency pulsation. That's why three-phase motors run smoothly and quietly.

> **Δ load example.** A balanced Δ load of $30 + j40\ \Omega$ per phase is connected to 240 V lines.
>
> Each phase sees the line voltage: $I_p = 240/50 = 4.8$ A, so $I_L = \sqrt3(4.8) = 8.31$ A.
>
> $P = 3I_p^2R = 3(4.8)^2(30) = 2074$ W.

## Key takeaways

- Y: $V_L = \sqrt3 V_p$, $I_L = I_p$. Δ: $V_L = V_p$, $I_L = \sqrt3 I_p$. $\mathbf Z_Y = \mathbf Z_\Delta/3$.
- Solve balanced systems per phase (phase a), then shift by ∓120°.
- $P = \sqrt3 V_L I_L\cos\theta$, and total instantaneous power is constant.
