## Frequency response

Set $s = j\omega$ in a transfer function and you get the **frequency response** $H(j\omega)$: a complex number at each frequency, giving the gain $|H(j\omega)|$ and phase shift $\angle H(j\omega)$ applied to a sinusoid of that frequency. A **Bode plot** graphs both against frequency on a **logarithmic** axis, with the gain in **decibels**:

$$
|H|_{\text{dB}} = 20\log_{10}|H(j\omega)|
$$

| Gain | dB |
|---|---|
| 10 | +20 dB |
| 2 | +6.02 dB |
| $\sqrt2$ | +3.01 dB |
| 1 | 0 dB |
| $1/\sqrt2 = 0.707$ | −3.01 dB |
| 0.1 | −20 dB |

Logarithms turn products into sums, so a transfer function built from factors becomes a **sum** of simple shapes. That's why Bode plots can be sketched by hand.

## The building blocks

Write $H(j\omega)$ in terms of standard factors and add their contributions:

| Factor | Magnitude | Phase |
|---|---|---|
| Constant $K$ | flat at $20\log_{10}|K|$ | 0° (or 180° if $K<0$) |
| Zero at origin, $j\omega$ | +20 dB/decade line through 0 dB at $\omega = 1$ | +90° |
| Pole at origin, $1/(j\omega)$ | −20 dB/decade | −90° |
| Real pole, $\dfrac{1}{1 + j\omega/\omega_p}$ | 0 dB, then −20 dB/dec above $\omega_p$; −3 dB at $\omega_p$ | 0° → −90°, −45° at $\omega_p$ |
| Real zero, $1 + j\omega/\omega_z$ | 0 dB, then +20 dB/dec above $\omega_z$; +3 dB at $\omega_z$ | 0° → +90°, +45° at $\omega_z$ |
| Complex pole pair ($\omega_0$, $\zeta$) | −40 dB/dec above $\omega_0$, with a resonant peak if $\zeta < 0.707$ | 0° → −180° |

The **asymptotes** (straight-line approximations) are within 3 dB everywhere for real poles and zeros.

## Worked example

> $$
> H(s) = \frac{100(s + 10)}{(s + 1)(s + 1000)}
> $$
>
> **Normalize** each factor to the form $(1 + s/\omega_k)$:
> $$
> H(s) = \frac{100\cdot10}{1\cdot1000}\cdot\frac{1 + s/10}{(1 + s)(1 + s/1000)} = 1\cdot\frac{1 + s/10}{(1+s)(1 + s/1000)}
> $$
>
> So the low-frequency gain is 1 (0 dB). Walking up in frequency:
>
> - **Below 1 rad/s:** flat at 0 dB.
> - **1 rad/s** (pole): slope becomes −20 dB/dec.
> - **10 rad/s** (zero): slope returns to 0. The gain has fallen one decade at −20 dB/dec, so it is flat at −20 dB.
> - **1000 rad/s** (pole): slope −20 dB/dec again; −60 dB by $10^5$ rad/s.
>
> ```plot
> x: 0.01, 1e5, ω (rad/s), log
> y: -70, 10, |H| (dB)
> f: 20*log10(100*sqrt(x^2 + 100)/(sqrt(x^2 + 1)*sqrt(x^2 + 1e6))) | exact magnitude
> f: -20*log10(max(x, 1)) + 20*log10(max(x, 10)/10) - 20*log10(max(x, 1000)/1000) | asymptotes | dash
> vline: 1, pole
> vline: 10, zero
> vline: 1000, pole
> caption: Exact magnitude and straight-line asymptotes. The largest error, 3 dB, occurs at each corner frequency.
> ```
>
> ```plot
> x: 0.01, 1e5, ω (rad/s), log
> y: -95, 5, ∠H (degrees)
> f: (atan(x/10) - atan(x) - atan(x/1000))*180/pi | phase
> caption: Phase. Each pole pulls toward −90° and each zero pushes back toward 0°.
> ```

## Practice

```quiz
? A filter's gain is 0.25. What is that in dB?
= -12.04 | 0.01 | dB
> $20\log_{10}0.25 = -12.04$ dB. Each halving is about −6 dB.
```

```quiz
? $H(s) = \dfrac{1000}{s + 100}$. What is the low-frequency gain in dB?
= 20 | 0.001 | dB
> $H(0) = 10$, and $20\log_{10}10 = 20$ dB.
```

```quiz
? For that same $H(s) = 1000/(s + 100)$, what is the gain in dB at $\omega = 100$ rad/s?
= 16.99 | 0.01 | dB
> At the corner the gain is 3 dB below the low-frequency value: $20 - 3.01 = 16.99$ dB.
```

```quiz
? What is the high-frequency slope of a transfer function with three poles and one zero (all real, finite)?
- −20 dB/decade
+ −40 dB/decade
- −60 dB/decade
- −80 dB/decade
> Each pole contributes −20 and each zero +20: $3(-20) + 20 = -40$ dB/dec.
```

```quiz
? A single real pole contributes what phase at its corner frequency?
= -45 | 0.001 | °
> $-\tan^{-1}(1) = -45^\circ$.
```

## Key takeaways

- $|H|_{dB} = 20\log_{10}|H|$; ±20 dB per decade per pole/zero.
- Normalize factors to $(1 + s/\omega_k)$, find the low-frequency gain, then change slope at each corner.
- Corners: −3 dB and −45° for a pole; asymptotes are within 3 dB.
