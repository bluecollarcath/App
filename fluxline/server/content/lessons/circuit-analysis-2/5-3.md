## Black boxes with two ports

Many circuits are used as a block between a source and a load: an amplifier, a filter, a transformer, a transmission line, a transistor. A **two-port network** describes such a block entirely by the relationship between the voltage and current at its input port and its output port, without caring what's inside.

```circuit
BOX 3,1 2,2 "linear network"
W 0.4,0.3 2,0.3
W 0.4,1.7 2,1.7
W 4,0.3 5.6,0.3
W 4,1.7 5.6,1.7
T 0.4,0.3 ""
T 0.4,1.7 ""
T 5.6,0.3 ""
T 5.6,1.7 ""
ARROW 0.7,0.3 1.5,0.3 I_1 color=anno
ARROW 5.3,0.3 4.5,0.3 I_2 color=anno side=-1
TEXT 0.15,1 V_1 anchor=end color=anno
TEXT 5.85,1 V_2 anchor=start color=anno
caption: Standard reference directions: both currents flow *into* the network at the top terminals.
```

Four variables, $V_1, I_1, V_2, I_2$, are related by two linear equations. Choosing which two are "inputs" gives the different parameter sets.

## The four common parameter sets

**Impedance (z) parameters:** voltages in terms of currents.
$$
\begin{bmatrix}V_1\\V_2\end{bmatrix} = \begin{bmatrix}z_{11}&z_{12}\\z_{21}&z_{22}\end{bmatrix}\begin{bmatrix}I_1\\I_2\end{bmatrix},
\qquad z_{11} = \left.\frac{V_1}{I_1}\right|_{I_2=0}, \ \ z_{21} = \left.\frac{V_2}{I_1}\right|_{I_2=0}, \ \ldots
$$
Found by open-circuiting one port at a time.

**Admittance (y) parameters:** currents in terms of voltages, $\mathbf I = \mathbf Y\mathbf V$. Found by short-circuiting one port at a time. $\mathbf Y = \mathbf Z^{-1}$.

**Hybrid (h) parameters:** $V_1 = h_{11}I_1 + h_{12}V_2$, $I_2 = h_{21}I_1 + h_{22}V_2$. The classic description of a bipolar transistor: $h_{fe} = h_{21}$ is its current gain $\beta$.

**Transmission (ABCD) parameters:** input in terms of output, with the output current taken as *leaving* port 2:
$$
\begin{bmatrix}V_1\\I_1\end{bmatrix} = \begin{bmatrix}A&B\\C&D\end{bmatrix}\begin{bmatrix}V_2\\-I_2\end{bmatrix}
$$

A **reciprocal** network (any network of R, L, C, and transformers, with no dependent sources) has $z_{12} = z_{21}$, $y_{12} = y_{21}$, and $AD - BC = 1$.

## Worked example: a T network

```circuit
T 0,0 ""
R 0,0 2,0 "Z₁ = 2 Ω"
R 2,0 4,0 "Z₂ = 4 Ω"
R 2,0 2,2 "Z₃ = 6 Ω"
T 4,0 ""
T 0,2 ""
W 0,2 2,2
W 2,2 4,2
T 4,2 ""
caption: A resistive T network.
```

> **z parameters.** With port 2 open, $I_1$ flows through $Z_1$ and $Z_3$: $z_{11} = Z_1 + Z_3 = 8\ \Omega$, and $V_2$ is the voltage across $Z_3$: $z_{21} = Z_3 = 6\ \Omega$. Similarly, $z_{22} = Z_2 + Z_3 = 10\ \Omega$ and $z_{12} = 6\ \Omega$. Reciprocal ✓.

## Interconnecting two-ports

The real power of two-port parameters is combining blocks:

| Connection | Rule |
|---|---|
| Series–series | $\mathbf Z = \mathbf Z_a + \mathbf Z_b$ |
| Parallel–parallel | $\mathbf Y = \mathbf Y_a + \mathbf Y_b$ |
| **Cascade** (output of one drives input of the next) | $\mathbf T = \mathbf T_a\mathbf T_b$ (multiply ABCD matrices) |

The basic ABCD building blocks:

$$
\text{series impedance } Z:\ \begin{bmatrix}1 & Z\\ 0 & 1\end{bmatrix}, \qquad
\text{shunt admittance } Y:\ \begin{bmatrix}1 & 0\\ Y & 1\end{bmatrix}
$$

> **The T network as a cascade:** series 2 Ω, shunt $\tfrac16$ S, series 4 Ω:
> $$\begin{bmatrix}1&2\\0&1\end{bmatrix}\begin{bmatrix}1&0\\\tfrac16&1\end{bmatrix}\begin{bmatrix}1&4\\0&1\end{bmatrix} = \begin{bmatrix}\tfrac43 & \tfrac{22}{3}\\[2pt] \tfrac16 & \tfrac53\end{bmatrix}$$
> Check: $AD - BC = \tfrac{20}{9} - \tfrac{22}{18} = 1$ ✓ (reciprocal).

### Input impedance with a load

With a load $Z_L$ on port 2:

$$
Z_{in} = \frac{AZ_L + B}{CZ_L + D}
$$

> For the T network with $Z_L = 10\ \Omega$: $Z_{in} = \dfrac{\tfrac43(10) + \tfrac{22}{3}}{\tfrac16(10) + \tfrac53} = \dfrac{20.67}{3.33} = 6.2\ \Omega$. (Directly: $2 + 6\parallel14 = 2 + 4.2 = 6.2\ \Omega$ ✓.)

Cascading ABCD matrices is exactly how long transmission lines, multi-stage filters, and RF chains are analyzed.

## Practice

```quiz
? A T network has $Z_1 = 5\ \Omega$, $Z_2 = 3\ \Omega$, $Z_3 = 10\ \Omega$ (shunt). What is $z_{11}$, in Ω?
= 15 | 0.001 | Ω
> $z_{11} = Z_1 + Z_3 = 15\ \Omega$.
```

```quiz
? For that same T network, what is $z_{21}$, in Ω?
= 10 | 0.001 | Ω
> With port 2 open, $V_2$ equals the voltage across the shunt arm: $z_{21} = Z_3 = 10\ \Omega$.
```

```quiz
? A two-port has $A = 2$, $B = 10\ \Omega$, $C = 0.1$ S, $D = 1$. What is its input impedance with a 20 Ω load, in Ω?
= 16.67 | 0.01 | Ω
> $Z_{in} = \frac{2(20) + 10}{0.1(20) + 1} = \frac{50}{3} = 16.67\ \Omega$.
```

```quiz
? Two two-ports are connected so the output of the first drives the input of the second. Which parameters combine by simple matrix multiplication?
- z parameters
- y parameters
- h parameters
+ ABCD (transmission) parameters
> Cascade connections multiply ABCD matrices.
```

```quiz
? Which network is guaranteed to be reciprocal ($z_{12} = z_{21}$)?
+ A ladder of resistors, capacitors, and inductors
- A transistor amplifier
- Any circuit containing a dependent source
- An op-amp buffer
> Passive RLC networks (and ideal transformers) are reciprocal; dependent sources generally break reciprocity.
```

## Key takeaways

- A two-port is characterized by $V_1, I_1, V_2, I_2$ and two equations.
- z (open-circuit), y (short-circuit), h (transistors), ABCD (cascades).
- Reciprocal networks: $z_{12} = z_{21}$, $AD - BC = 1$.
- Cascade = multiply ABCD; $Z_{in} = (AZ_L + B)/(CZ_L + D)$.
