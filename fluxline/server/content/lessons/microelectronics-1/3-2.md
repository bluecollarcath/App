## Biasing a BJT

The goal is the same as for MOSFETs: a stable active-mode operating point that doesn't depend on the poorly controlled $\beta$. The standard solution is again a voltage divider plus an emitter resistor.

```circuit
W 1.2,-0.4 3,-0.4
TEXT 2.1,-0.75 "V_{CC} = 12 V"
R 1.2,-0.4 1.2,2 "R_1 = 30 kΩ"
R 1.2,2 1.2,4.4 "R_2 = 10 kΩ"
W 1.2,2 2,2
NPN 3,2 ""
R 3,-0.4 3,1 "R_C = 3 kΩ"
R 3,3 3,4.4 "R_E = 1 kΩ"
W 1.2,4.4 3,4.4
GND 2.1,4.4
caption: Four-resistor bias for an NPN transistor ($\beta = 100$).
```

### Solving it

Unlike a MOSFET gate, the base draws current, so replace the divider with its **Thévenin equivalent**:

$$
V_{Th} = V_{CC}\frac{R_2}{R_1 + R_2}, \qquad R_{Th} = R_1 \parallel R_2
$$

KVL around the base–emitter loop, with $I_E = (\beta + 1)I_B$:

$$
I_B = \frac{V_{Th} - V_{BE}}{R_{Th} + (\beta + 1)R_E}
$$

> **Worked example.** $V_{Th} = 12 \cdot \frac{10}{40} = 3$ V, $R_{Th} = 7.5$ kΩ.
>
> $I_B = \dfrac{3 - 0.7}{7.5\ \text{k} + 101 \times 1\ \text{k}} = 21.2\ \mu$A, so $I_C = 2.12$ mA.
>
> $V_E = (\beta + 1)I_BR_E = 2.14$ V, $\quad V_C = 12 - 3(2.12) = 5.64$ V, $\quad V_{CE} = 3.50$ V.
>
> $V_{CE} > 0.2$ V, so the transistor is in active mode ✓.

**Why it's stable:** because $(\beta + 1)R_E = 101$ kΩ is much larger than $R_{Th} = 7.5$ kΩ, $I_E \approx (V_{Th} - 0.7)/R_E$, which doesn't depend on $\beta$ at all. Rule of thumb: make $R_{Th} \le 0.1(\beta + 1)R_E$.

## The BJT small-signal model

Linearizing the exponential at the operating point gives:

$$
g_m = \frac{I_C}{V_T}, \qquad r_\pi = \frac{\beta}{g_m}, \qquad r_e = \frac{\alpha}{g_m} \approx \frac{1}{g_m}, \qquad r_o = \frac{V_A}{I_C}
$$

The hybrid-π model is the MOSFET's with one difference: a resistance $r_\pi$ between base and emitter, because the base draws current.

> **For the example:** $g_m = 2.12\ \text{mA}/25.85\ \text{mV} = 82$ mS, $\quad r_\pi = 100/82\ \text{mS} = 1.22$ kΩ, $\quad r_e \approx 12\ \Omega$.

**BJT vs. MOSFET at the same current:** a BJT's $g_m = I_C/V_T$ beats a MOSFET's $2I_D/V_{ov}$ whenever $V_{ov} > 2V_T \approx 52$ mV, which is almost always. That's why BJTs remain popular for high-gain, low-noise analog stages.

```quiz
> $I_B = 2.3\ \text{V}/(7.5 + 202)\ \text{k}\Omega = 10.98\ \mu$A, so $I_C = 1.098$ mA. Doubling $R_E$ roughly halves the current.
```

```quiz

- It saturates the transistor
- It removes the base current
> The base current's drop across $R_{Th}$ becomes negligible.
```

## Key takeaways

- Replace the divider with its Thévenin equivalent; $I_B = (V_{Th} - 0.7)/[R_{Th} + (\beta+1)R_E]$.
- Stable bias: $R_{Th} \ll (\beta + 1)R_E$. Verify $V_{CE} > 0.2$ V.
- $g_m = I_C/V_T$, $r_\pi = \beta/g_m$, $r_e \approx 1/g_m$, $r_o = V_A/I_C$.
