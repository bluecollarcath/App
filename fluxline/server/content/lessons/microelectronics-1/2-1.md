## The most important device ever made

The **MOSFET** (metal-oxide-semiconductor field-effect transistor) is the building block of every processor, memory chip, and power converter. Over $10^{22}$ have been manufactured, more than any other human-made object.

An n-channel MOSFET (NMOS) has four terminals: gate (G), drain (D), source (S), and body. The gate sits above the silicon on a thin insulating oxide. A positive gate voltage attracts electrons to the surface, forming a conducting **channel** between source and drain. The gate draws **no DC current**: it's a capacitor.


## Three regions of operation

The key parameters are the **threshold voltage** $V_t$ (typically 0.3–1 V) and the process transconductance $k_n = \mu_nC_{ox}(W/L)$, set by the device's width-to-length ratio. Define the **overdrive voltage** $V_{ov} = v_{GS} - V_t$.

| Region | Condition | Drain current |
|---|---|---|
| **Cutoff** | $v_{GS} < V_t$ | $i_D = 0$ |
| **Triode** (linear) | $v_{GS} > V_t$ and $v_{DS} < V_{ov}$ | $i_D = k_n\left(V_{ov}\,v_{DS} - \tfrac12 v_{DS}^2\right)$ |
| **Saturation** | $v_{GS} > V_t$ and $v_{DS} \ge V_{ov}$ | $i_D = \tfrac12 k_n V_{ov}^2\,(1 + \lambda v_{DS})$ |

In saturation the current barely depends on $v_{DS}$: the MOSFET acts like a **current source** controlled by $v_{GS}$. That's the region used for amplifiers. Digital logic switches between cutoff (off) and deep triode (on, acting like a small resistor).

The factor $(1 + \lambda v_{DS})$ models **channel-length modulation**: in saturation the current still rises slightly with $v_{DS}$. You'll see $\lambda$ again as the output resistance $r_o$.

```plot
x: 0, 3, v_{DS} (V)
y: 0, 2.6, i_D (mA)
f: 2*((1 - u(x - 0.5))*(0.5*x - x^2/2) + u(x - 0.5)*0.125*(1 + 0.05*(x - 0.5))) | V_{GS} = 1.0 V
f: 2*((1 - u(x - 1))*(1*x - x^2/2) + u(x - 1)*0.5*(1 + 0.05*(x - 1))) | V_{GS} = 1.5 V
f: 2*((1 - u(x - 1.5))*(1.5*x - x^2/2) + u(x - 1.5)*1.125*(1 + 0.05*(x - 1.5))) | V_{GS} = 2.0 V
caption: Output characteristics for $k_n = 2$ mA/V², $V_t = 0.5$ V. Left of each knee is triode; right is saturation, where the curves are nearly flat.
```

> **Worked example.** $k_n = 2$ mA/V², $V_t = 0.5$ V, $V_{GS} = 1.5$ V, so $V_{ov} = 1$ V (ignore $\lambda$).
>
> - With $V_{DS} = 2$ V $\ge V_{ov}$: saturation, $i_D = \tfrac12(2)(1)^2 = 1$ mA.
> - With $V_{DS} = 0.3$ V $< V_{ov}$: triode, $i_D = 2(1 \times 0.3 - 0.045) = 0.51$ mA.

## PMOS

A **p-channel** MOSFET is the mirror image: it conducts when the gate is *below* the source by more than $|V_t|$, and current flows from source to drain. The equations are the same with every voltage and current reversed in sign. CMOS logic pairs one NMOS with one PMOS so that one is always off, which is why it uses almost no static power.

## Key takeaways

- $V_{ov} = v_{GS} - V_t$. Cutoff below threshold; triode when $v_{DS} < V_{ov}$; saturation when $v_{DS} \ge V_{ov}$.
- Saturation: $i_D = \tfrac12k_nV_{ov}^2(1 + \lambda v_{DS})$, a voltage-controlled current source.
- The gate draws no DC current. PMOS mirrors NMOS with reversed polarities.
