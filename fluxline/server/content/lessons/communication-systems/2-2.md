## Mapping bits to symbols

A digital modulator turns groups of bits into **symbols**, each a particular amplitude and phase of the carrier. With $M$ possible symbols, each carries

$$
k = \log_2M \ \text{bits}, \qquad R_b = kR_s
$$

The carrier is usually written in terms of two quadrature components, $s(t) = I\cos2\pi f_ct - Q\sin2\pi f_ct$, so each symbol is a point $(I, Q)$ in a plane: the **constellation diagram**.

## The main schemes

| Scheme | Symbols | Bits/symbol | Varies |
|---|---|---|---|
| OOK / ASK | carrier on/off, or levels | 1 (or more) | amplitude |
| BPSK | 2 phases, $0°$ and $180°$ | 1 | phase |
| QPSK | 4 phases | 2 | phase |
| 8-PSK | 8 phases | 3 | phase |
| 16-QAM | $4 \times 4$ grid | 4 | amplitude and phase |
| 64-QAM, 256-QAM, 1024-QAM | larger grids | 6, 8, 10 | amplitude and phase |

- **BPSK** is the most robust: two points as far apart as possible, $\pm\sqrt{E_b}$. GPS and deep-space links use it.
- **QPSK** puts one BPSK signal on $I$ and another on $Q$. It doubles the bit rate in the **same** bandwidth with the same bit-error rate, which is why it's everywhere (satellite TV, the robust modes of Wi-Fi and LTE).
- **M-PSK** keeps a constant amplitude (good for efficient, nonlinear power amplifiers), but the points crowd together on the circle as $M$ grows.
- **QAM** uses the whole plane, so it packs more points for the same average energy. Wi-Fi, 5G and cable modems switch between QPSK and up to 1024-QAM depending on signal quality.

## The price of more bits per symbol

For a fixed average energy, more points means points closer together, so less noise is needed to push the received point across a decision boundary. Each doubling of $M$ in QAM costs roughly **3 dB** more SNR for the same error rate (6 dB per extra bit on each axis). Higher-order modulation trades **power** for **bandwidth efficiency**:

$$
\eta = \frac{R_b}{B} \approx \frac{\log_2M}{1 + \alpha}\ \text{b/s/Hz}
$$

> **Example.** At 5 Msym/s, QPSK carries 10 Mb/s, 16-QAM carries 20 Mb/s, and 256-QAM carries 40 Mb/s, all in the same bandwidth. But 256-QAM needs about 18 dB more SNR than QPSK, so only users close to the base station get it. This is **adaptive modulation**, done thousands of times a second in modern systems.

## Gray coding

When noise does cause an error, the receiver almost always picks a **neighboring** point. **Gray coding** labels the constellation so that neighbors differ in exactly one bit. A symbol error then usually costs just one bit error out of $k$.

- It uses error-correcting codes

```

```

## Key takeaways

- Constellations show symbols as $(I, Q)$ points; $\log_2M$ bits per symbol.
- BPSK/QPSK are robust; QAM packs more bits per symbol at the cost of SNR (about 3 dB per doubling of $M$).
- Spectral efficiency $\approx \log_2M/(1 + \alpha)$; adaptive modulation picks $M$ from the SNR.
- Gray coding turns most symbol errors into single-bit errors.
