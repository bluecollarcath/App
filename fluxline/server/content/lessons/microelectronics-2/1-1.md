## Why IC designers bias with current

On an integrated circuit, resistors are large and inaccurate (±20%), but **transistors match each other** extremely well. So analog ICs set bias currents with **current mirrors**: copies of a single reference current, scaled by transistor geometry.

## The basic MOSFET mirror

$M_1$ is diode-connected (gate tied to drain) and carries $I_{REF}$. $M_2$ shares the same $V_{GS}$. In saturation, ignoring channel-length modulation,

$$
I_D = \tfrac12\mu_nC_{ox}\frac{W}{L}(V_{GS} - V_t)^2
\quad\Rightarrow\quad
\boxed{\frac{I_{OUT}}{I_{REF}} = \frac{(W/L)_2}{(W/L)_1}}
$$

```circuit
LINE 0.6,-0.6 1.4,-0.6
TEXT 1,-0.9 V_{DD}
I 1,-0.6 1,1 I_{REF} side=-1
NMOS 1,2 M_1 mirror
NMOS 3,2 M_2
W 1,1 2,1
W 2,1 2,2
T 3,0 ""
W 3,0 3,1 i=I_{OUT}
W 1,3 2,3
W 2,3 3,3
GND 2,3
caption: A basic NMOS current mirror. $M_1$ is diode-connected, so both transistors share the same $V_{GS}$.
```

The ratio depends only on geometry — process parameters cancel.

## Output resistance

A real current source has finite output resistance. With channel-length modulation, $M_2$'s output resistance is

$$
R_{out} = r_{o2} = \frac{1}{\lambda I_{OUT}} \approx \frac{V_A}{I_{OUT}}
$$

Any difference between $V_{DS2}$ and $V_{DS1}$ creates a current error of $\Delta V_{DS}/r_o$. Higher $R_{out}$ means a better current source and, in an amplifier, higher gain.

## The cascode mirror

Stacking a second transistor on top (a cascode) multiplies output resistance by roughly the intrinsic gain $g_m r_o$:

$$
R_{out} \approx g_m r_o^2
$$

The cost is **headroom**: the output must stay above about $V_t + 2V_{ov}$ instead of $V_{ov}$. Low-voltage designs use "wide-swing" cascode variants to recover some of it.

## BJT mirrors

The same idea works with BJTs, with $I_{OUT}/I_{REF} = A_{E2}/A_{E1}$ (emitter area ratio). Finite $\beta$ introduces an error, since base currents come out of $I_{REF}$:

$$
\frac{I_{OUT}}{I_{REF}} = \frac{1}{1 + 2/\beta}
$$

Adding a helper transistor (beta-helper) or using a Wilson mirror reduces this error.

```quiz
> Current scales with the aspect ratio: $4 \times 100 = 400$ µA.
```

```quiz
> $r_o = 1/(0.05 \times 200\times10^{-6}) = 100$ kΩ.
```


## Key takeaways

- Mirrors copy and scale currents using geometry ratios.
- Output resistance ($r_o$, or $g_m r_o^2$ for a cascode) determines quality.
- Cascodes trade headroom for output resistance.
