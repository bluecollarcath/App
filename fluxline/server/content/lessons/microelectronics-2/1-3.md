## Building an op-amp from parts

A single transistor stage gives a gain of maybe 20 to 100. An op-amp needs $10^4$ to $10^6$, a high input resistance, and a low output resistance. So op-amps are **multistage** amplifiers, each stage chosen for one job:

```circuit
ARROW -0.4,-0.4 0.6,-0.4
ARROW -0.4,0.4 0.6,0.4
TEXT -0.55,-0.4 v_+ anchor=end
TEXT -0.55,0.4 v_− anchor=end
BOX 1.6,0 2,1.6 "Diff pair"
ARROW 2.6,0 3.6,0
BOX 4.6,0 2,1.6 "CS gain stage"
ARROW 5.6,0 6.6,0
BOX 7.6,0 2,1.6 "Output buffer"
ARROW 8.6,0 9.6,0 v_{out}
TEXT 1.6,1.2 "A_1 ≈ 100" color=muted size=13
TEXT 4.6,1.2 "A_2 ≈ 100" color=muted size=13
TEXT 7.6,1.2 "A_3 ≈ 1" color=muted size=13
caption: The classic op-amp architecture: a differential input stage, a high-gain second stage, and (when driving heavy loads) a unity-gain output buffer.
```

1. **Input stage:** the actively loaded differential pair (Lesson 1.2). It gives high input resistance, rejects common-mode signals, converts to single-ended, and provides gain $A_1 = g_{m1}(r_{o2} \parallel r_{o4})$.
2. **Gain stage:** a common-source stage with a current-source load, $A_2 = g_{m6}(r_{o6} \parallel r_{o7})$.
3. **Output stage:** a source or emitter follower, or a push-pull pair (Lesson 4.1), so the gain doesn't collapse into a low-resistance load. Many CMOS op-amps that only drive capacitive loads on-chip leave it out.

The gains multiply:

$$
A_v = A_1A_2A_3
$$

> **Worked example.** Stage 1: $g_{m1} = 1$ mS, $r_{o2} \parallel r_{o4} = 100$ kΩ, so $A_1 = 100$. Stage 2: $g_{m6} = 4$ mS, $r_{o6} \parallel r_{o7} = 25$ kΩ, so $A_2 = 100$. Total: $A_v = 10^4$ (80 dB), the typical open-loop gain of a CMOS op-amp.

## Loading between stages

Each stage's output resistance meets the next stage's input resistance. For MOSFET stages that input is a gate, so there is no DC loading at all; that's one reason CMOS op-amps cascade so cleanly. For BJT stages the next stage's $r_\pi$ appears in parallel with the previous output and must be included: the first stage's gain becomes $g_{m1}(R_{out1} \parallel R_{in2})$.

## Slew rate

The op-amp's internal capacitance, mostly the compensation capacitor $C_c$ across the second stage (Lesson 3.2), can only be charged by the current the input stage can supply, at most the tail current $I_{SS}$. That limits how fast the output can change:

$$
\text{SR} = \frac{I_{SS}}{C_c}
$$

With $I_{SS} = 100\ \mu$A and $C_c = 5$ pF, $\text{SR} = 20$ V/µs. A sine of amplitude $V_p$ needs slew rate $2\pi fV_p$, so the **full-power bandwidth** is

$$
f_{max} = \frac{\text{SR}}{2\pi V_p}
$$

Above it, a large sine output turns into a triangle wave. For a 10 V peak output at 20 V/µs, that's 318 kHz.

## DC offset

With both inputs grounded, an ideal op-amp outputs 0 V. A real one doesn't, because of:

- **Systematic offset:** a design imbalance, such as the first stage's output DC level not matching what the second stage needs. Fixed by careful sizing.
- **Random offset:** mismatch between "identical" transistors ($V_t$ and $W/L$ differ slightly). Larger devices match better.

It's quoted as an **input offset voltage** $V_{OS}$: the input voltage that would bring the output back to zero, which is the output error divided by the gain. Typical CMOS values are 1–10 mV; precision and chopper op-amps reach microvolts. In a closed loop with noise gain $1 + R_2/R_1$, the output error is $V_{OS}(1 + R_2/R_1)$.

```quiz
= 202 | 0.001 | mV
> The offset is amplified by the noise gain: $2 \times 101 = 202$ mV.
```

```quiz
? Why do CMOS op-amp stages cascade without loading each other at DC?
+ Each stage drives a MOSFET gate, which draws no DC current
- MOSFETs have zero output resistance
- The compensation capacitor isolates the stages
- CMOS stages all have unity gain
> A gate is an open circuit at DC, so the previous stage's output isn't divided down.
```

## Key takeaways

- Op-amp = differential input stage + high-gain stage (+ output buffer); stage gains multiply.
- Slew rate $= I_{SS}/C_c$ limits large-signal speed; full-power bandwidth $= \text{SR}/(2\pi V_p)$.
- Offset is referred to the input as $V_{OS}$ and is amplified by the noise gain.
