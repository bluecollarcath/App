## A function is a rule

A **function** is a rule that takes an input and gives exactly one output. Think of it as a machine: put a number in, get a number out.

$$
f(x) = 2x + 1
$$

This says: the function named $f$ takes an input $x$, doubles it and adds 1. Read $f(x)$ as "$f$ of $x$."

**Evaluating** a function means replacing $x$ with a number:

$$
f(3) = 2(3) + 1 = 7
$$

So the input 3 produces the output 7.

### Common mistake

**$f(x)$ is not "$f$ times $x$."** The parentheses here hold the input, like a slot in the machine. $f(3)$ means "feed 3 into $f$."

## Evaluating carefully

When the input is negative or a whole expression, **wrap it in parentheses** before substituting. It prevents most sign mistakes.

> **Example 1.** Let $g(x) = x^2 - 3x$. Find $g(-2)$.
>
> $$
> g(-2) = (-2)^2 - 3(-2) = 4 + 6 = 10
> $$
>
> Without the parentheses, it's easy to write $-2^2 = -4$, which is wrong (Lesson 1.1).

> **Example 2.** Engineers often use $t$ for time. If the height of a dropped ball is $h(t) = 20 - 5t^2$ meters after $t$ seconds, then after 1 second, $h(1) = 20 - 5 = 15$ m, and after 2 seconds, $h(2) = 20 - 20 = 0$ m: it hits the ground.

The letter doesn't matter. $f(x)$, $g(t)$, $v(t)$ (voltage over time) and $I(V)$ (current as a function of voltage) all work the same way.

## The coordinate plane

To draw a function, we use two perpendicular number lines:

- the horizontal **$x$-axis** for inputs;
- the vertical **$y$-axis** for outputs.

Every point is written $(x, y)$: first how far **right** (negative means left), then how far **up** (negative means down). The point $(3, 2)$ is 3 right and 2 up; $(-2, 3)$ is 2 left and 3 up. Where the axes cross is the **origin**, $(0, 0)$.

## Graphing a function

A function's **graph** is every point $(x, f(x))$. To sketch one, make a table of values and plot the points.

> **Example 3.** Graph $f(x) = \tfrac{1}{2}x^2 - 2$.
>
> | $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
> |---|---|---|---|---|---|---|
> | $f(x)$ | $0$ | $-1.5$ | $-2$ | $-1.5$ | $0$ | $2.5$ |

```plot
x: -3.5, 3.5, x
y: -3, 4.5, y
f: 0.5*x^2 - 2 | f(x) = ½x² − 2
mark: -2, 0, (−2, 0)
mark: 0, -2, (0, −2)
mark: 2, 0, (2, 0)
mark: 3, 2.5, (3, 2.5)
hline: 0
vline: 0
caption: Plotting points from the table, then joining them smoothly, gives the graph. Every point on the curve is an (input, output) pair.
```

Reading a graph works the other way: to find $f(3)$, go to $x = 3$ on the horizontal axis, go up to the curve, and read the height: $2.5$.

## The vertical line test

Because a function gives **exactly one** output for each input, no vertical line can cross its graph more than once. If some vertical line hits a graph twice, that graph is **not** a function, since one input would have two outputs. A circle, for example, fails this test.

## Domain and range

- The **domain** is the set of inputs that are allowed.
- The **range** is the set of outputs that actually happen.

Most functions accept any number. Two common exceptions:

- **You can't divide by zero.** $f(x) = \dfrac{1}{x}$ has every number in its domain **except** $0$.
- **You can't take the square root of a negative number** (with ordinary numbers). $g(x) = \sqrt{x - 2}$ needs $x - 2 \ge 0$, so its domain is $x \ge 2$.

For range: $x^2$ is never negative, so $f(x) = x^2$ has range $y \ge 0$.

## Functions in engineering

Almost every engineering relationship is a function. Ohm's law says the current through a 220 Ω resistor depends on the voltage across it:

$$
I(V) = \frac{V}{220}
$$

Put in 11 V and you get $I(11) = 0.05$ A. A graph of $I$ against $V$ is how lab instruments display a component's behavior, and reading such graphs is a skill you'll use constantly.

## Key takeaways

- A function gives exactly one output for each input; $f(x)$ means "$f$ of $x$," not multiplication.
- Substitute inputs in parentheses, especially negative ones.
- A point $(x, y)$ is $x$ across and $y$ up; a graph is all the points $(x, f(x))$.
- Vertical line test: a graph is a function if no vertical line crosses it twice.
- Domain: the allowed inputs (no dividing by zero, no square roots of negatives). Range: the outputs that occur.
