## The impulse response says everything

Feed an LTI system a unit impulse $\delta(t)$ and record its output, the **impulse response** $h(t)$. Because any input can be written as a sum (integral) of shifted, scaled impulses, and because the system is linear and time-invariant, the output to any input is the corresponding sum of shifted, scaled impulse responses. That sum is the **convolution integral**:

$$
y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t - \tau)\,d\tau
$$

Know $h(t)$ and you can predict the response to anything.

## Computing convolution: flip, shift, multiply, integrate

For each output time $t$:
1. **Flip** $h(\tau)$ to get $h(-\tau)$.
2. **Shift** it by $t$: $h(t - \tau)$.
3. **Multiply** by $x(\tau)$.
4. **Integrate** over $\tau$: that area is $y(t)$.

As $t$ increases, the flipped impulse response slides across the input from left to right.

> **Worked example.** An RC low-pass filter with $\tau = 0.5$ s has $h(t) = 2e^{-2t}u(t)$. Find its response to a unit step, $x(t) = u(t)$.
>
> For $t < 0$ the two functions don't overlap, so $y = 0$. For $t \ge 0$ they overlap on $0 \le \tau \le t$:
> $$
> y(t) = \int_0^t 2e^{-2(t - \tau)}\,d\tau = 1 - e^{-2t}
> $$
> This is the familiar RC charging curve. At $t = 1$ s, $y = 1 - e^{-2} = 0.865$.

> **Worked example: two pulses.** Convolve a pulse of height 1 on $[0, 2]$ with a pulse of height 1 on $[0, 1]$.
>
> - $0 \le t < 1$: the sliding pulse is entering, so the overlap grows: $y = t$.
> - $1 \le t < 2$: the short pulse is fully inside the long one: $y = 1$.
> - $2 \le t < 3$: it's leaving: $y = 3 - t$.
>
> ```plot
> x: -0.5, 3.5, t
> y: -0.1, 1.3
> f: u(x) - u(x - 2) | x(t) | dash
> f: u(x) - u(x - 1) | h(t) | dot
> f: max(0, min(min(x, 1), 3 - x)) | y(t) = x(t) * h(t)
> caption: Convolving a 2-second pulse with a 1-second pulse gives a trapezoid that lasts $2 + 1 = 3$ seconds.
> ```

## Useful properties

| Property | Statement |
|---|---|
| Commutative | $x * h = h * x$ |
| Associative | $(x * h_1) * h_2 = x * (h_1 * h_2)$: cascaded systems combine by convolving their impulse responses |
| Distributive | $x * (h_1 + h_2) = x * h_1 + x * h_2$: parallel systems add |
| Identity | $x * \delta = x$ |
| Shift | $x(t) * \delta(t - t_0) = x(t - t_0)$ |
| Width | widths add: if $x$ lasts $T_1$ and $h$ lasts $T_2$, then $y$ lasts $T_1 + T_2$ |
| Area | area of $y$ = (area of $x$) × (area of $h$) |

The **step response** is the integral of the impulse response: $s(t) = \int_{-\infty}^{t} h(\tau)\,d\tau$. Measure a step response in the lab, differentiate it, and you have $h(t)$.

```quiz
= 0.6321 | 0.01 |

```

```quiz
? In the two-pulse example, what is $y(2.5)$?
= 0.5 | 0.01 |
> On $2 \le t < 3$, $y = 3 - t = 0.5$.
```

```quiz
? A pulse lasting 4 ms is convolved with an impulse response lasting 3 ms. How long does the output last, in ms?
= 7 | 0 | ms
> Widths add: $4 + 3 = 7$ ms.
```

```quiz
? $x(t)$ has area 3 and $h(t)$ has area 0.5. What is the area of $y = x * h$?
= 1.5 | 0.001 |
> Areas multiply.
```

```quiz
? Two LTI systems with impulse responses $h_1$ and $h_2$ are connected in series. The overall impulse response is:
- $h_1 + h_2$
- $h_1 h_2$
+ $h_1 * h_2$
- $h_1 - h_2$
> Cascading convolves; parallel connection adds.
```

## Key takeaways

- An LTI system is completely described by $h(t)$; the output is $y = x * h$.
- Compute by flip, shift, multiply, integrate.
- Widths add and areas multiply; cascades convolve; the step response is the integral of $h$.
