## What is a system?

A **system** transforms an input signal $x$ into an output signal $y$. A circuit, an amplifier, a filter, a motor, a radio channel, a camera sensor, and a block of DSP code are all systems. Before calculating anything, engineers classify a system by a handful of properties, because the properties decide which mathematical tools apply.

Write $x(t) \to y(t)$ to mean "input $x$ produces output $y$."

## Linearity

A system is **linear** if it obeys **superposition**: if $x_1 \to y_1$ and $x_2 \to y_2$, then for any constants $a, b$,

$$
a\,x_1 + b\,x_2 \;\to\; a\,y_1 + b\,y_2
$$

Two quick tests catch most nonlinear systems:
- **Zero in, zero out.** A linear system must map $x = 0$ to $y = 0$. So $y = 3x - 2$ is *not* linear (it's "affine"), even though its graph is a straight line.
- **Scaling.** Doubling the input must double the output. $y = x^2$ fails.

## Time invariance

A system is **time-invariant** if delaying the input simply delays the output:

$$
x(t) \to y(t) \quad\Longrightarrow\quad x(t - t_0) \to y(t - t_0)
$$

The system behaves the same today as tomorrow. Two classic failures:
- $y(t) = t\,x(t)$: the gain depends on the clock time.
- $y(t) = x(2t)$: delaying the input by $t_0$ delays the output by only $t_0/2$.

**Linear + time-invariant = LTI.** LTI systems are the heart of this course: they're completely described by a single function, the impulse response, and they're analyzed with convolution and Fourier and Laplace transforms. Resistors, capacitors, inductors and op-amp filters are LTI (within their ratings).

## Causality and memory

- **Causal:** the output at time $t$ depends only on the input at times $\le t$. Every real-time physical system is causal. $y[n] = x[n+1]$ is not, but it's perfectly usable when processing recorded data.
- **Memoryless:** the output depends only on the input at the same instant. A resistor ($v = iR$) is memoryless; a capacitor, which integrates current, has memory.

## Stability

A system is **BIBO stable** (bounded-input, bounded-output) if every bounded input produces a bounded output. An integrator $y(t) = \int_{-\infty}^t x(\tau)\,d\tau$ is *unstable*: a constant input makes its output grow without limit. For LTI systems, stability has an easy test: the impulse response must be absolutely integrable, $\int |h(t)|\,dt < \infty$. Equivalently, every pole lies in the left half-plane (continuous time) or inside the unit circle (discrete time), as you'll see in Unit 4.

## Worked classification

| System | Linear | Time-invariant | Causal | Stable |

## Practice

```quiz
? Is the system $y(t) = 3x(t) + 2$ linear?
- Yes, its graph is a straight line
+ No, a zero input gives a nonzero output
- Only for positive inputs
- Only if it's also time-invariant
> Linear systems must map zero to zero. This one is affine.
```

```quiz
? Which system is NOT time-invariant?
- $y(t) = x(t - 1)$
- $y(t) = 2x(t)$
+ $y(t) = x(2t)$
- $y(t) = x(t) + x(t - 1)$
> Time scaling breaks time invariance: a delay of $t_0$ at the input becomes $t_0/2$ at the output.
```

```quiz
? The system $y(t) = \int_{t-1}^{t} x(\tau)\,d\tau$ (a 1-second running integral) receives an input with $|x(t)| \le 2$ for all $t$. What is the largest $|y(t)|$ can be?
= 2 | 0.001 |
> The integral covers a 1-second window, so $|y| \le 2 \times 1 = 2$. This system is BIBO stable.
```

```quiz
? Which system is non-causal?
- $y[n] = x[n] - x[n-1]$
- $y[n] = 0.5\,y[n-1] + x[n]$
+ $y[n] = x[n+1] - x[n]$
- $y[n] = 3x[n]$
> It needs the next input sample, $x[n+1]$, before it's available.
```

## Key takeaways

- Linear: superposition holds (zero in, zero out). Time-invariant: delays pass through unchanged.
- LTI systems are fully described by their impulse response.
- Causal: no peeking at future inputs. BIBO stable: bounded in, bounded out.
