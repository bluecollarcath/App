## Registers

A **register** is a group of flip-flops sharing one clock, storing a multi-bit value: an $n$-bit register is $n$ D flip-flops side by side. Registers hold everything a processor works on: operands, addresses, the program counter, status flags.

A register usually needs a **load enable**: a 2-to-1 MUX in front of each $D$ input feeds back the current $Q$ when enable is 0 (hold) and new data when it's 1 (load). This is far better than gating the clock, which causes timing problems.

## Shift registers

Connect each flip-flop's $Q$ to the next one's $D$, and every clock edge moves the data one position:

```circuit
T 0.2,-0.4 "serial in"
W 0.2,-0.4 0.8,-0.4
DFF 2,0 FF_0 noqn
W 3.2,-0.4 3.8,-0.4
DFF 5,0 FF_1 noqn
W 6.2,-0.4 6.8,-0.4
DFF 8,0 FF_2 noqn
W 9.2,-0.4 9.8,-0.4
T 9.8,-0.4 "serial out"
TEXT 3.5,-0.75 Q_0 color=anno size=13
TEXT 6.5,-0.75 Q_1 color=anno size=13
W 0.8,0.4 0.5,0.4 0.5,1.3
W 3.8,0.4 3.5,0.4 3.5,1.3
W 6.8,0.4 6.5,0.4 6.5,1.3
W 0,1.3 0.5,1.3
W 0.5,1.3 3.5,1.3
W 3.5,1.3 6.5,1.3
T 0,1.3 CLK
caption: A 3-bit shift register. Each clock edge moves every bit one stage to the right.
```

Uses:
- **Serial ↔ parallel conversion**: UART, SPI, and USB send bits one at a time; shift registers assemble them into bytes (serial-in, parallel-out) or break bytes into bits (parallel-in, serial-out).
- **Delay lines**: an $n$-stage shift register delays a signal by $n$ clock cycles.
- **Multiplying or dividing by 2**: a binary shift left doubles a number; shift right halves it.

## Counters

A **binary counter** adds 1 on each clock edge. In a synchronous counter, every flip-flop shares the clock, and bit $i$ toggles when all lower bits are 1:

$$
T_0 = 1,\quad T_1 = Q_0,\quad T_2 = Q_0Q_1,\quad T_3 = Q_0Q_1Q_2,\ \ldots
$$

An $n$-bit counter cycles through $2^n$ states, $0$ to $2^n - 1$, then wraps to 0.

**Mod-$N$ counters** reset early, after $N$ states. A decade (mod-10) counter needs $\lceil\log_2 10\rceil = 4$ flip-flops and resets after 1001. Counters divide frequency too: the MSB of an $n$-bit counter toggles at $f_{clk}/2^n$.

**Ripple counters** clock each flip-flop from the previous stage's output instead of a shared clock. They're simpler but slower, and their outputs glitch through intermediate values as the ripple passes. Avoid them except for simple frequency division.

### Other sequences

| Counter | Flip-flops | States | Notes |
|---|---|---|---|
| Binary | $n$ | $2^n$ | general purpose |
| Ring (one-hot) | $n$ | $n$ | one 1 circulates; no decoding needed |
| Johnson (twisted ring) | $n$ | $2n$ | inverted feedback; glitch-free decoding |
| Gray-code | $n$ | $2^n$ | one bit changes per step; used in position encoders |

## Practice

```quiz
? How many flip-flops does a counter need to count from 0 to 59 (for a clock's seconds)?
= 6 | 0 |
> 60 states need $\lceil\log_2 60\rceil = 6$ bits ($2^6 = 64$).
```

```quiz
? A 4-bit shift register initially holds $1011$ (left = first stage). After one shift right with a serial input of 0, what does it hold, in decimal?
= 5 | 0 |
> $1011 \to 0101 = 5$: the rightmost 1 shifts out, a 0 enters on the left.
```

```quiz
? An 8-bit binary counter runs from a 1 MHz clock. At what frequency does its MSB toggle as a square wave, in Hz?
= 3906.25 | 0.01 | Hz
> The MSB completes one cycle every $2^8 = 256$ clocks: $10^6/256 = 3906.25$ Hz.
```

```quiz
? How many distinct states does a 5-flip-flop Johnson counter cycle through?
= 10 | 0 |
> A Johnson counter has $2n = 10$ states.
```

## Key takeaways

- A register is $n$ D flip-flops with a shared clock; use a MUX for load enable, not a gated clock.
- Shift registers convert serial ↔ parallel and delay signals.
- Synchronous counters: bit $i$ toggles when all lower bits are 1. Mod-$N$ needs $\lceil\log_2N\rceil$ flip-flops.
