## Describing hardware with text

Drawing gates stops scaling at a few dozen gates. Real chips have billions. **Hardware description languages (HDLs)** let you describe hardware in text, which tools then **simulate** (to check behavior) and **synthesize** (turn into actual gates or FPGA configuration). The two dominant HDLs are **Verilog** (and its extension SystemVerilog) and **VHDL**. This course uses Verilog.

**The key mindset shift:** Verilog looks like a programming language, but it describes *hardware that all exists at once*. Every `assign` statement is a piece of circuitry running in parallel, not a line executed in order.

## Modules

The unit of design is a **module**, a box with ports:

```verilog
module mux2 (
  input  wire a,
  input  wire b,
  input  wire sel,
  output wire y
);
  assign y = sel ? b : a;   // 2-to-1 multiplexer
endmodule
```

## Values and vectors

- Each bit is `0`, `1`, `x` (unknown), or `z` (high impedance, undriven).
- Buses are vectors: `wire [7:0] data;` is 8 bits, with `data[7]` the MSB.
- Literals give width, base, and value: `4'b1010`, `8'hFF`, `16'd1000`.
- Concatenation joins bits: `{2'b10, 3'b011}` is `5'b10011`.

| Operator | Meaning |
|---|---|
| `& \| ^ ~` | bitwise AND, OR, XOR, NOT |
| `&& \|\| !` | logical (true/false) operators |
| `+ - *` | arithmetic |
| `== != < >` | comparison |
| `<< >>` | shifts |
| `c ? a : b` | conditional (a MUX) |

## Continuous assignment

`assign` describes combinational logic that updates whenever its inputs change:

```verilog
module full_adder (
  input  wire a, b, cin,
  output wire sum, cout
);
  assign sum  = a ^ b ^ cin;
  assign cout = (a & b) | (cin & (a ^ b));
endmodule
```

Larger designs **instantiate** smaller modules, connecting their ports, exactly like placing chips on a board.

## Combinational `always` blocks

For logic that's easier to describe step by step, use `always @(*)` (or `always_comb` in SystemVerilog). A 4-to-1 MUX:

```verilog
module mux4 (
  input  wire [1:0] sel,
  input  wire [3:0] d,
  output reg        y
);
  always @(*) begin
    case (sel)
      2'b00: y = d[0];
      2'b01: y = d[1];
      2'b10: y = d[2];
      default: y = d[3];
    endcase
  end
endmodule
```

### The #1 beginner bug: accidental latches

In a combinational `always` block, **every output must be assigned on every path**. If some case leaves `y` unassigned, synthesis infers a *latch* to "remember" the old value. That's almost never what you want, and it breaks timing. Use a `default` case, or assign a default value at the top of the block.

## Key takeaways

- HDLs describe hardware for simulation and synthesis; Verilog statements describe parallel circuits.
- Modules, vectors (`[7:0]`), sized literals (`8'hFF`), concatenation (`{a, b}`).
- `assign` for simple logic; `always @(*)` for complex logic, and assign every output on every path.
