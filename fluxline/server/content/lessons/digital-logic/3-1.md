## Circuits with memory

Combinational circuits forget: their outputs depend only on current inputs. **Sequential circuits** remember. Their outputs depend on the history of inputs, which is stored in **state**. Memory comes from feedback: wire a gate's output back to its input.

## The SR latch

Two cross-coupled NOR gates hold a bit:

```circuit
T 1,-0.4 R
W 1,-0.4 2,-0.4
NOR 3,0
NOR 3,2
T 1,2.4 S
W 1,2.4 2,2.4
W 4,0 4.4,0
W 4.4,0 5.2,0
T 5.2,0 Q
W 4,2 4.4,2
W 4.4,2 5.2,2
T 5.2,2 Q̄
W 4.4,0 4.4,0.6 1.6,1.3 1.6,1.6 2,1.6
W 4.4,2 4.4,1.4 1.6,0.7 1.6,0.4 2,0.4
caption: An SR latch: each NOR's output feeds the other's input.
```

| $S$ | $R$ | $Q$ next | Action |
|---|---|---|---|
| 0 | 0 | $Q$ | hold (remember) |
| 1 | 0 | 1 | set |
| 0 | 1 | 0 | reset |
| 1 | 1 | — | invalid: both outputs forced to 0 |

## The D latch

Avoid the invalid state by deriving $S$ and $R$ from one data input $D$, gated by an enable $E$: $S = ED$, $R = E\overline{D}$. When $E = 1$ the latch is **transparent** ($Q$ follows $D$); when $E = 0$ it holds its last value.

Transparency is a problem in synchronous systems: while the enable is high, changes can race through several latches in a row.

## The D flip-flop

A **D flip-flop** samples $D$ only at the **rising edge** of the clock and holds that value for the whole cycle. It's built from two D latches in series (master and slave) enabled on opposite clock phases. It's the fundamental storage element of digital design.

```circuit
T 0.2,-0.4 D
W 0.2,-0.4 0.8,-0.4
T 0.2,0.4 CLK
W 0.2,0.4 0.8,0.4
DFF 2,0
W 3.2,-0.4 3.8,-0.4
T 3.8,-0.4 Q
W 3.2,0.4 3.8,0.4
T 3.8,0.4 Q̄
caption: The D flip-flop symbol. The triangle marks an edge-triggered clock input.
```

### Timing requirements

$D$ must be stable for a **setup time** $t_{setup}$ before the edge and a **hold time** $t_{hold}$ after it. After the edge, $Q$ changes within the **clock-to-Q delay** $t_{clk\text{-}q}$. A register-to-register path then requires

$$
T_{clk} \ge t_{clk\text{-}q} + t_{\text{logic}} + t_{setup}
$$

Violating setup or hold can leave a flip-flop **metastable**, stuck between 0 and 1 for an unpredictable time. That's why signals from other clock domains pass through two-flip-flop synchronizers.

## Other flip-flops

- **T flip-flop**: toggles when $T = 1$, holds when $T = 0$. Natural for counters.
- **JK flip-flop**: like SR, but $J = K = 1$ toggles instead of being invalid.

In modern design almost everything uses D flip-flops, with extra logic in front of $D$ to get other behavior.

## Practice

```quiz
? An SR latch (NOR type) holds $Q = 0$. $S$ pulses to 1 and returns to 0 while $R = 0$. What is $Q$ afterward?
= 1 | 0 |
> The set pulse makes $Q = 1$, and with $S = R = 0$ the latch holds it.
```

```quiz
? A T flip-flop starts at $Q = 0$ with $T = 1$. What is $Q$ after 5 rising clock edges?
= 1 | 0 |
> It toggles on each edge: 1, 0, 1, 0, 1.
```

```quiz
? A register-to-register path has $t_{clk\text{-}q} = 1$ ns, 5 ns of logic, and $t_{setup} = 0.5$ ns. What is the maximum clock frequency, in MHz?
= 153.8 | 0.01 | MHz
> $T_{min} = 6.5$ ns, so $f_{max} = 1/6.5\ \text{ns} = 153.8$ MHz.
```

```quiz
? What is the key difference between a D latch and a D flip-flop?
- A latch stores two bits
+ A latch is transparent while enabled; a flip-flop samples only at a clock edge
- A flip-flop has no clock
- A latch cannot hold its value
> Edge triggering is what lets synchronous systems advance cleanly, one step per clock.
```

## Key takeaways

- Feedback creates memory: the SR latch holds a bit; avoid $S = R = 1$.
- D latch: transparent while enabled. D flip-flop: samples $D$ at the clock edge.
- $T_{clk} \ge t_{clk\text{-}q} + t_{logic} + t_{setup}$; violating timing risks metastability.
