## Why engineers program

Modern EE work is inseparable from code: simulating circuits, processing measurements, controlling instruments, writing firmware. This course uses **Python** for analysis and **C** for embedded work. We start with Python.

## Variables and types

```python
R1 = 4.7e3        # float: 4.7 kΩ
n_samples = 1024  # int
name = "buck converter"  # str
enabled = True    # bool
```

Python is dynamically typed: a variable's type is whatever you last assigned. Use scientific notation (`4.7e3`) for engineering values — it keeps units readable.

**Integer vs. float division** trips up everyone once:

```python
7 / 2   # 3.5   true division
7 // 2  # 3     floor division
7 % 2   # 1     remainder
```

## Control flow

```python
v_out = 3.6
if v_out > 3.3:
    print("Over-voltage!")
elif v_out < 3.0:
    print("Under-voltage")
else:
    print("OK")

for k in range(5):        # 0, 1, 2, 3, 4
    print(k, 2**k)
```

Indentation *is* syntax in Python — blocks are defined by consistent indentation (four spaces).

## Functions

Encapsulate any calculation you will do twice:

```python
def parallel(*resistors):
    """Equivalent resistance of resistors in parallel."""
    return 1 / sum(1 / r for r in resistors)

def divider(v_in, r_top, r_bottom):
    return v_in * r_bottom / (r_top + r_bottom)

print(parallel(6e3, 3e3))         # 2000.0
print(divider(9, 10e3, 5e3))      # 3.0
```

Good engineering functions have a docstring, take values in SI units, and return a value rather than printing it.

## Lists and comprehensions

```python
E12 = [1.0, 1.2, 1.5, 1.8, 2.2, 2.7, 3.3, 3.9, 4.7, 5.6, 6.8, 8.2]
kilo = [x * 1e3 for x in E12]
closest = min(kilo, key=lambda r: abs(r - 4000))   # 3900.0
```

That last line finds the nearest standard E12 resistor to a computed 4 kΩ — a task you will do constantly in design.
