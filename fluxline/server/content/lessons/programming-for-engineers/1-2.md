## Why NumPy

Plain Python lists are flexible but slow for numbers: a loop over a million samples runs one interpreted step at a time. **NumPy** stores numbers in compact typed arrays and runs operations on whole arrays in compiled code, typically 10–100 times faster, with shorter code. It's the foundation of essentially all scientific Python (SciPy, pandas, matplotlib, scikit-learn, PyTorch).

```python
import numpy as np

v = np.array([1.2, 3.4, 5.6])      # 1-D array (a vector)
G = np.array([[0.75, -0.25],
              [-0.25, 0.375]])      # 2-D array (a matrix)
print(v.shape, G.shape)            # (3,) (2, 2)
```

## Creating arrays

```python
t = np.linspace(0, 1e-3, 1001)   # 1001 evenly spaced points from 0 to 1 ms
f = np.arange(0, 1000, 100)      # 0, 100, ..., 900 (end excluded)
z = np.zeros(8); o = np.ones((3, 3)); I = np.eye(4)
```

`linspace` (number of points) is usually better than `arange` (step size) for floats, since it hits both endpoints exactly.

## Vectorization: no loops

Arithmetic and math functions apply **element by element** to whole arrays:

```python
f0 = 1e3                                  # 1 kHz
t = np.linspace(0, 2e-3, 2001)            # two periods
v = 5 * np.sin(2 * np.pi * f0 * t)        # a 5 V peak sine, all samples at once
v_rms = np.sqrt(np.mean(v**2))            # RMS by definition
print(round(v_rms, 3))                    # 3.535  (5/√2)
```

Compare the loop version: `for k in range(len(t)): v[k] = 5*math.sin(...)`. Vectorized code is faster and reads like the equation.

Useful reductions: `np.sum`, `np.mean`, `np.max`, `np.argmax` (index of the max), `np.std`, `np.cumsum`, and `np.trapezoid` (called `np.trapz` before NumPy 2.0) for numerical integration.

## Indexing and masks

```python
x = np.array([3, -1, 4, -1, 5, -9])
x[0], x[-1]          # 3, -9  (first, last)
x[1:4]               # [-1, 4, -1]  (slice: start included, end excluded)
x[x < 0]             # [-1, -1, -9]  (boolean mask)
np.count_nonzero(x > 0)   # 3
```

Boolean masks are the vectorized way to filter data: find samples above a threshold, clip outliers, select a time window.

## Broadcasting

Operations between arrays of different shapes "stretch" the smaller one when the shapes are compatible:

```python
R = np.array([100, 220, 470])      # three resistors (shape (3,))
V = np.array([[1.0], [5.0]])       # two voltages as a column (shape (2, 1))
I = V / R                          # shape (2, 3): every voltage over every resistor
```

## Linear algebra: solving circuits

NumPy's `linalg` module solves the matrix equations of nodal analysis directly (Linear Algebra, Lesson 1.2):

```python
G = np.array([[1/2 + 1/4, -1/4],
              [-1/4, 1/4 + 1/8]])   # conductance matrix (S)
i = np.array([3.0, 0.0])            # 3 A injected at node 1
v = np.linalg.solve(G, i)
print(np.round(v, 3))               # [5.143 3.429]
```

Use `np.linalg.solve`, never `np.linalg.inv(G) @ i`: it's faster and more accurate. Other tools: `@` (matrix multiply), `np.linalg.eig`, `np.linalg.svd`, `np.linalg.lstsq` (least squares), `np.linalg.cond`.

## Key takeaways

- NumPy arrays are fast, typed and vectorized: write math on whole arrays, not loops.
- Create with `array`, `linspace`, `arange`, `zeros`; reduce with `sum`, `mean`, `max`.
- Index with slices and boolean masks; broadcasting combines compatible shapes.
- Solve circuits with `np.linalg.solve`.
