## Working with individual bits

Hardware speaks in bits: a status register where bit 3 means "data ready," a GPIO port where each bit is a pin, a sensor that packs a 12-bit reading and 4 flag bits into one 16-bit word. C's **bitwise operators** manipulate them directly.

| Operator | Meaning | Example (8-bit) |
|---|---|---|
| `&` | AND | `0b1100 & 0b1010 = 0b1000` |
| `\|` | OR | `0b1100 \| 0b1010 = 0b1110` |
| `^` | XOR | `0b1100 ^ 0b1010 = 0b0110` |
| `~` | NOT (invert all bits) | `~0b00001111 = 0b11110000` |
| `<<` | shift left | `0b0001 << 3 = 0b1000` |
| `>>` | shift right | `0b1000 >> 2 = 0b0010` |

Write constants in hexadecimal (each hex digit is 4 bits: `0xF0` = `0b11110000`), or in binary with `0b` (supported by GCC and C23).

## The four essential idioms

With a **mask** having a 1 in each bit position you care about:

```c
reg |=  (1u << n);    /* SET bit n          */
reg &= ~(1u << n);    /* CLEAR bit n        */
reg ^=  (1u << n);    /* TOGGLE bit n       */
if (reg & (1u << n))  /* TEST bit n         */
```

Always use unsigned constants (`1u`): shifting a signed 1 into the sign bit is undefined behavior.

## Multi-bit fields

To write a field of several bits, first clear it with a mask, then OR in the new value, shifted into place:

```c
/* bits 6..4 hold a 3-bit "gain" setting */
#define GAIN_POS   4u
#define GAIN_MASK  (0x7u << GAIN_POS)            /* 0b0111_0000 */

reg = (reg & ~GAIN_MASK) | ((gain << GAIN_POS) & GAIN_MASK);  /* write */
uint8_t g = (reg & GAIN_MASK) >> GAIN_POS;                    /* read  */
```

> **Unpacking a sensor reading.** A 16-bit word holds a 12-bit result in bits 15..4 and flags in bits 3..0. With `w = 0xABC5`: the result is `w >> 4 = 0xABC = 2748`, and the flags are `w & 0xF = 5`.

## Shifts as fast arithmetic

For unsigned integers, `x << n` multiplies by $2^n$ and `x >> n` divides by $2^n$ (rounding down). Compilers do this automatically for constant powers of two, but it's why buffer sizes and averaging windows are often powers of two: a moving average of 16 samples divides with `>> 4`.

## Signed numbers and two's complement

Signed integers use **two's complement**: to negate, invert all bits and add 1. In 8 bits, −1 is `0xFF` and −20 is `0xEC`. An ADC or sensor returning a signed 12-bit value in a 16-bit register needs **sign extension** before use:

```c
int16_t v = (int16_t)(raw << 4) >> 4;   /* move bit 11 to bit 15, then arithmetic-shift back */
```

(Right-shifting a negative signed value is implementation-defined in older C standards, but every common compiler shifts in copies of the sign bit.)

## Bit tricks worth knowing

- `x & (x - 1)` clears the lowest set bit; `(x & (x - 1)) == 0` tests for a power of two (for nonzero `x`).
- Parity, counting set bits (`__builtin_popcount`), and finding the lowest set bit (`__builtin_ctz`) have compiler builtins that compile to single instructions on most CPUs.

## Key takeaways

- Set with `|=`, clear with `&= ~`, toggle with `^=`, test with `&`; use unsigned masks like `(1u << n)`.
- Multi-bit fields: clear with the mask, then OR in the shifted value; read with mask and shift.
- Shifts multiply and divide unsigned values by powers of two.
- Two's complement: invert and add one; sign-extend narrow signed fields.
