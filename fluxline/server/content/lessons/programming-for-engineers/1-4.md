## Letting the computer integrate

Differential Equations taught you to solve circuits by hand. Real designs (nonlinear parts, measured inputs, many states) need numerical solutions. SciPy's `solve_ivp` implements the Runge–Kutta and implicit methods of Differential Equations Lesson 4.2, with automatic step-size control.

## A first-order circuit

An RC circuit driven by a 5 V step: $RC\,\dfrac{dv}{dt} = V_s - v$.

```python
import numpy as np
from scipy.integrate import solve_ivp

R, C, Vs = 1e3, 1e-6, 5.0          # 1 kΩ, 1 µF → τ = 1 ms

def rc(t, y):
    v = y[0]
    return [(Vs - v) / (R * C)]     # dv/dt

sol = solve_ivp(rc, t_span=(0, 5e-3), y0=[0.0],
                t_eval=np.linspace(0, 5e-3, 501), rtol=1e-8)
v_end = sol.y[0, -1]
print(round(v_end, 4))              # 4.9663 = 5(1 − e^−5)
```

The pattern is always the same:

1. write a function `f(t, y)` that returns the derivatives of the state vector `y`;
2. call `solve_ivp(f, (t0, t1), y0, ...)`;
3. read the results from `sol.t` and `sol.y` (one row per state variable).

Checking against a case with a known answer (here $5(1 - e^{-5})$) before trusting the code on harder problems is good practice.

## A second-order circuit: series RLC

Choose the states as capacitor voltage and inductor current (the energy-storage variables):

$$
\frac{dv_C}{dt} = \frac iC, \qquad \frac{di}{dt} = \frac{V_s - Ri - v_C}{L}
$$

```python
R, L, C, Vs = 20.0, 10e-3, 1e-6, 1.0     # ζ = 0.1: underdamped

def rlc(t, y):
    vc, i = y
    return [i / C, (Vs - R * i - vc) / L]

sol = solve_ivp(rlc, (0, 5e-3), [0.0, 0.0], max_step=1e-6)
print(round(sol.y[0].max(), 3))          # peak v_C ≈ 1.729: 73% overshoot
```

The peak matches the formula $1 + e^{-\zeta\pi/\sqrt{1 - \zeta^2}} = 1.729$ for $\zeta = 0.1$ (Control Systems, Lesson 2.1).

## Nonlinear parts

Numerical solvers don't care about linearity. A half-wave rectifier (a 60 Hz source, a diode, and a filter capacitor across a load) just needs the Shockley diode equation in the derivative function:

```python
Is, VT = 1e-14, 0.02585      # diode saturation current, thermal voltage
RL, C = 1e3, 100e-6          # 1 kΩ load, 100 µF filter capacitor

def rectifier(t, y):
    vc = y[0]
    vs = 5 * np.sin(2 * np.pi * 60 * t)
    vd = min(vs - vc, 0.9)                 # clip to keep exp() from overflowing
    i_d = Is * (np.exp(vd / VT) - 1)       # Shockley diode current
    return [(i_d - vc / RL) / C]

sol = solve_ivp(rectifier, (0, 0.1), [0.0], method="BDF", max_step=1e-4)
print(round(sol.y[0].max(), 2))  # peak output 4.29 V: 5 V minus the diode drop
```

Exponential device equations make problems **stiff** (Differential Equations, Lesson 4.2). If `solve_ivp` crawls, switch to an implicit method: `method="Radau"` or `method="BDF"`.

## DC circuits: just linear algebra

For resistive networks, build the conductance matrix and call `np.linalg.solve` (Lesson 1.2). Wrapping it in a function that builds $G$ from a list of components is a few dozen lines, and it's the core of every circuit simulator.

```python
def nodal(n_nodes, resistors, sources):
    """resistors: (node_a, node_b, ohms); sources: (node, amps). Node 0 is ground."""
    G = np.zeros((n_nodes, n_nodes)); i = np.zeros(n_nodes)
    for a, b, r in resistors:
        g = 1 / r
        for p in (a, b):
            if p: G[p-1, p-1] += g
        if a and b:
            G[a-1, b-1] -= g; G[b-1, a-1] -= g
    for node, amps in sources:
        i[node-1] += amps
    return np.linalg.solve(G, i)

print(np.round(nodal(2, [(1, 0, 2), (1, 2, 4), (2, 0, 8)], [(1, 3)]), 3))  # [5.143 3.429]
```

## Key takeaways

- `solve_ivp(f, (t0, t1), y0)` with `f(t, y)` returning derivatives; results in `sol.t`, `sol.y`.
- Choose energy-storage variables (capacitor voltages, inductor currents) as states.
- Validate against analytic cases before trusting a model.
- Nonlinear parts are easy numerically; stiff problems need `BDF` or `Radau`.
- DC networks reduce to building $G$ and calling `np.linalg.solve`.
