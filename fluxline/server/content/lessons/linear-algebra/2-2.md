## How many equations really count?

An $m \times n$ matrix may have redundant rows or columns. Its **rank** $r$ is the number of pivots after elimination: the number of truly independent rows, which always equals the number of independent columns.

## The four fundamental subspaces

Every matrix $A$ ($m \times n$, rank $r$) defines four subspaces:

| Subspace | Lives in | Dimension | Meaning |
|---|---|---|---|
| **Column space** $C(A)$ | $\mathbb R^m$ | $r$ | all $\mathbf b$ for which $A\mathbf x = \mathbf b$ has a solution |
| **Null space** $N(A)$ | $\mathbb R^n$ | $n - r$ | all $\mathbf x$ with $A\mathbf x = \mathbf 0$ |
| **Row space** $C(A^T)$ | $\mathbb R^n$ | $r$ | combinations of the rows |
| **Left null space** $N(A^T)$ | $\mathbb R^m$ | $m - r$ | combinations of rows that give zero |

The null space is perpendicular to the row space, and the left null space to the column space.

## Rank–nullity

$$
\dim C(A) + \dim N(A) = r + (n - r) = n
$$

Every unknown either is pinned down by an independent equation or is a free direction in the null space.

The complete solution of $A\mathbf x = \mathbf b$ (when one exists) is

$$
\mathbf x = \mathbf x_p + \mathbf x_n
$$

one **particular** solution plus **anything** in the null space. If the null space is just $\mathbf 0$, the solution is unique.

> $A = \begin{bmatrix} 1 & 2 & 1 & 0 \\ 2 & 4 & 3 & 1 \\ 3 & 6 & 4 & 1 \end{bmatrix}$: row 3 = row 1 + row 2, so $r = 2$. The null space has dimension $4 - 2 = 2$, and the left null space dimension $3 - 2 = 1$ (spanned by $(1, 1, -1)$, the combination of rows that gives zero).

## The circuit interpretation

A circuit's topology is a matrix too. The **incidence matrix** $A$ of a network with $n$ nodes and $b$ branches has a row per branch, with $-1$ and $+1$ at the branch's two nodes. Then:

- $A\mathbf v$ gives the branch voltages from the node voltages. Adding a constant to every node voltage changes nothing, so $(1, 1, \ldots, 1)$ is in the null space: rank $= n - 1$ for a connected circuit. That's why one node must be chosen as **ground**.
- $A^T\mathbf i = \mathbf 0$ is **Kirchhoff's current law**. Its solutions, the left null space of $A$, are currents that circulate in loops. Its dimension is $b - (n - 1)$: the number of **independent loops**, which is the number of mesh equations you need.

> A circuit with 6 branches and 4 nodes has $6 - 3 = 3$ independent loops: 3 mesh currents, or 3 node voltages (4 nodes minus ground). Linear algebra explains why both methods give the right number of equations.

## Key takeaways

- Rank = number of pivots = independent rows = independent columns.
- Four subspaces: column ($r$), null ($n - r$), row ($r$), left null ($m - r$).
- Complete solution = particular + null-space part; unique iff $N(A) = \{\mathbf 0\}$.
- Circuit incidence matrices have rank $n - 1$ (hence a ground node) and $b - n + 1$ independent loops.
