## Every matrix, decomposed

Eigenvectors only work for square matrices, and not always even then. The **singular value decomposition** works for **every** matrix, square or rectangular:

$$
A = U\Sigma V^T
$$

- $V$ ($n \times n$, orthogonal): orthonormal input directions;
- $\Sigma$ ($m \times n$, diagonal): the **singular values** $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$;
- $U$ ($m \times m$, orthogonal): orthonormal output directions.

So $A\mathbf v_i = \sigma_i\mathbf u_i$: every matrix maps an orthonormal set of input directions to an orthonormal set of output directions, stretching each by $\sigma_i$. Geometrically, any linear map is a **rotation, then a stretch along the axes, then another rotation**, taking the unit circle to an ellipse whose semi-axes are the singular values.

## Computing singular values

The singular values are the square roots of the eigenvalues of $A^TA$ (which is symmetric, with non-negative eigenvalues); the $\mathbf v_i$ are its eigenvectors.

> $A = \begin{bmatrix} 3 & 0 \\ 4 & 5 \end{bmatrix}$: $A^TA = \begin{bmatrix} 25 & 20 \\ 20 & 25 \end{bmatrix}$, with eigenvalues 45 and 5. So $\sigma_1 = \sqrt{45} = 6.71$ and $\sigma_2 = \sqrt5 = 2.24$. The unit circle maps to an ellipse with semi-axes 6.71 and 2.24.

## What the singular values tell you

- **Rank** = the number of nonzero singular values (and in practice, the number above the noise level: a robust way to find the "effective rank" of measured data).
- **Norm:** the largest gain of the matrix, $\max\|A\mathbf x\|/\|\mathbf x\| = \sigma_1$.
- **Condition number:** $\kappa = \sigma_{max}/\sigma_{min}$ (Lesson 1.3). The example has $\kappa = 3$: very well conditioned.
- In control and MIMO systems (Communication Systems, Lesson 3.3), the singular values of the channel or transfer matrix are the gains of the independent "directions" through which signals can pass: each is a parallel spatial stream.

## Low-rank approximation

Write the SVD as a sum of rank-one pieces, largest first:

$$
A = \sigma_1\mathbf u_1\mathbf v_1^T + \sigma_2\mathbf u_2\mathbf v_2^T + \cdots
$$

Keeping only the first $k$ terms gives the **best possible** rank-$k$ approximation (Eckart–Young theorem), with error $\sigma_{k+1}$.

> **Image compression.** A $1000 \times 1000$ grayscale image needs 1,000,000 numbers. If its singular values fall off quickly, the first 50 terms capture most of it, using $50 \times (1000 + 1000 + 1) = 100\,050$ numbers, a 10× reduction.

The same idea is **principal component analysis** (PCA): find the few directions that capture most of the variation in a data set. It's used to denoise signals, compress sensor arrays, reduce model order, and in recommendation systems and machine learning.

## The pseudo-inverse

For any matrix, the **pseudo-inverse** $A^+ = V\Sigma^+U^T$ (invert the nonzero singular values, leave the zeros) gives the least-squares solution of $A\mathbf x = \mathbf b$ (Lesson 2.4) with the smallest norm, even when $A$ is rank-deficient or non-square. Small singular values can be zeroed out (truncated) to stop noise from being amplified: regularization.

## Key takeaways

- Every matrix factors as $A = U\Sigma V^T$: rotate, stretch by $\sigma_i$, rotate.
- $\sigma_i = \sqrt{\text{eig}(A^TA)}$; rank = nonzero $\sigma$'s; $\|A\| = \sigma_1$; $\kappa = \sigma_{max}/\sigma_{min}$.
- Truncated SVD gives the best low-rank approximation (compression, PCA, denoising).
- The pseudo-inverse solves least squares for any matrix.
