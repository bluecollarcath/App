## What an op-amp is

An **operational amplifier** is a high-gain differential amplifier with two inputs ($v_+$, non-inverting; $v_-$, inverting) and one output:

$$
v_o = A\,(v_+ - v_-)
$$

Real op-amps have open-loop gain $A$ of $10^5$–$10^6$, input resistance in the MΩ–TΩ range, and low output resistance. The output is limited to roughly the supply rails ($\pm V_{CC}$). Used open-loop, an op-amp is nearly useless — the slightest input difference saturates the output. Used with **negative feedback**, it becomes the most versatile building block in analog design.

## The ideal op-amp model

Assume $A \to \infty$, $R_{in} \to \infty$, $R_{out} \to 0$. With negative feedback present, two rules follow:

1. **No current flows into either input:** $i_+ = i_- = 0$.
2. **Virtual short:** the output adjusts so that $v_+ = v_-$.

Rule 2 is a consequence, not a physical short: with infinite gain, any finite output requires zero input difference. These rules hold **only** when there is negative feedback (output connected back to the inverting input).

## The inverting amplifier

Input $v_i$ through $R_1$ to $v_-$; feedback resistor $R_f$ from output to $v_-$; $v_+$ grounded.

Since $v_+ = 0$, rule 2 gives $v_- = 0$ (a **virtual ground**). KCL at $v_-$, using rule 1:

$$
\frac{v_i - 0}{R_1} + \frac{v_o - 0}{R_f} = 0
\quad\Rightarrow\quad
\boxed{\frac{v_o}{v_i} = -\frac{R_f}{R_1}}
$$

The input resistance seen by the source is just $R_1$.

## The non-inverting amplifier

Input $v_i$ to $v_+$; $R_f$ from output to $v_-$; $R_g$ from $v_-$ to ground.

Now $v_- = v_i$, and $v_-$ is a divider of the output: $v_- = v_o \frac{R_g}{R_g + R_f}$. So

$$
\boxed{\frac{v_o}{v_i} = 1 + \frac{R_f}{R_g}}
$$

The input resistance is ideally infinite — the source supplies no current.

## The voltage follower (buffer)

Set $R_f = 0$ and $R_g = \infty$: $v_o = v_i$. Gain of 1, but infinite input resistance and zero output resistance. A buffer **isolates** a high-impedance source (e.g., a voltage divider) from a load — the cure for the loading problem from the divider lesson.

## Analysis strategy for any op-amp circuit

1. Confirm negative feedback exists.
2. Write $v_+ = v_-$.
3. Write KCL at the inverting (and/or non-inverting) input, with zero input current.
4. **Never write KCL at the output node** — the op-amp output supplies whatever current is needed, and that current is unknown.
5. Check the answer against the supply rails. If $|v_o|$ exceeds the rail, the op-amp saturates and the linear analysis is invalid.

> **Worked example.** Inverting amp, $R_1 = 10$ kΩ, $R_f = 47$ kΩ, $\pm 12$ V supplies. For $v_i = 0.2$ V: $v_o = -4.7 \times 0.2 = -0.94$ V. For $v_i = 3$ V, the formula predicts $-14.1$ V, but the output clips near $-12$ V (in practice a volt or so less).

## Key takeaways

- With negative feedback: $i_\pm = 0$ and $v_+ = v_-$.
- Inverting: $-R_f/R_1$. Non-inverting: $1 + R_f/R_g$. Follower: 1.
- Always check results against the supply rails.
