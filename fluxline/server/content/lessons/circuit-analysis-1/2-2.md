## The idea

**Mesh analysis** is the dual of nodal analysis. The unknowns are **mesh currents** — fictitious currents circulating around each mesh (a loop with no other loop inside it). Every branch current is either a mesh current or the difference of two adjacent mesh currents, so KCL is satisfied automatically, and we only need KVL.

Mesh analysis applies to **planar** circuits — circuits that can be drawn without crossing wires.

## The procedure

1. **Assign a mesh current** to each of the $b - n + 1$ meshes, all clockwise by convention.
2. **Write KVL around each mesh.** For a resistor shared between mesh $k$ and mesh $j$, the voltage drop in the direction of $i_k$ is $R(i_k - i_j)$.
3. **Solve** for the mesh currents.

## Example: two meshes

> Left mesh: a 24 V source (driving current clockwise) and $R_1 = 4\ \Omega$. Shared branch: $R_2 = 6\ \Omega$. Right mesh: $R_3 = 2\ \Omega$ and a 10 V source that *opposes* the clockwise current.
>
> **Mesh 1:** $-24 + 4i_1 + 6(i_1 - i_2) = 0 \;\Rightarrow\; 10i_1 - 6i_2 = 24$
>
> **Mesh 2:** $6(i_2 - i_1) + 2i_2 + 10 = 0 \;\Rightarrow\; -6i_1 + 8i_2 = -10$
>
> Solving: $i_1 = 3$ A, $i_2 = 1$ A. The shared 6 Ω resistor carries $i_1 - i_2 = 2$ A.
>
> **Power check:** the 24 V source delivers $72$ W. Resistors absorb $36 + 24 + 2 = 62$ W, and the 10 V source *absorbs* 10 W (it is being charged). $62 + 10 = 72$. ✓

## The resistance matrix by inspection

For circuits with only resistors and independent voltage sources, $\mathbf{R}\mathbf{i} = \mathbf{v}$ where:

- $R_{kk}$ = total resistance around mesh $k$,
- $R_{kj}$ = *negative* of the resistance shared by meshes $k$ and $j$,
- $v_k$ = net source voltage driving current *in the direction* of mesh $k$.

For the example: $\begin{bmatrix} 10 & -6 \\ -6 & 8 \end{bmatrix}\begin{bmatrix} i_1 \\ i_2\end{bmatrix} = \begin{bmatrix} 24 \\ -10\end{bmatrix}$.

## Current sources and supermeshes

- A current source on the **outer edge** of a mesh fixes that mesh current directly.
- A current source **shared** between two meshes creates a **supermesh**: write one KVL equation around the combined loop that avoids the current source, plus the constraint $i_a - i_b = I_s$.

## Nodal or mesh?

| Prefer **nodal** when… | Prefer **mesh** when… |
|---|---|
| fewer nodes than meshes | fewer meshes than nodes |
| many current sources | many voltage sources |
| circuit is non-planar | you need branch currents directly |
| op-amp circuits | |

In practice nodal analysis is more common, since it works for every circuit and maps directly to computer solvers.

## Key takeaways

- Unknowns are mesh currents; write KVL around each mesh.
- Shared resistor drop: $R(i_k - i_j)$.
- Shared current source → supermesh + constraint.
- Choose the method that gives fewer equations.
