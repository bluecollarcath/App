## The idea

Kirchhoff's laws alone will solve any circuit, but writing them ad hoc gets messy fast. **Nodal analysis** is a systematic method that always produces exactly the right number of independent equations. It is the method SPICE uses internally (as *modified* nodal analysis).

The unknowns are **node voltages** — the voltage of each node relative to a chosen reference node (ground).

## The procedure

1. **Choose a reference node** (usually the one with the most connections, or the bottom rail). Label it 0 V.
2. **Label the remaining $n-1$ node voltages** $v_1, v_2, \ldots$
3. **Write KCL at each non-reference node**, expressing every resistor current with Ohm's law in terms of node voltages. The current leaving node $a$ through resistor $R$ toward node $b$ is
$$ i_{a\to b} = \frac{v_a - v_b}{R} $$
4. **Solve** the resulting $n-1$ simultaneous equations.

A convenient habit: write every KCL equation as *"sum of currents leaving through resistors = sum of source currents entering."*

## Example: two nodes, two current sources

> A 3 A source injects current into node 1; a 3 A source injects current into node 2. Resistors: $R_1 = 6\ \Omega$ from node 1 to ground, $R_2 = 4\ \Omega$ between nodes 1 and 2, $R_3 = 2\ \Omega$ from node 2 to ground.
>
```circuit
I 0,2 0,0 "3 A"
W 0,0 2,0
R 2,0 2,2 "6 Ω"
R 2,0 4,0 "4 Ω"
R 4,0 4,2 "2 Ω"
W 4,0 6,0
I 6,2 6,0 "3 A" side=-1
W 0,2 2,2
W 2,2 4,2
W 4,2 6,2
GND 3,2
TEXT 2,-0.4 v_1
TEXT 4,-0.4 v_2
caption: Two non-reference nodes, $v_1$ and $v_2$, measured from the ground node along the bottom rail.
```

> **Node 1:** $\dfrac{v_1}{6} + \dfrac{v_1 - v_2}{4} = 3$
>
> **Node 2:** $\dfrac{v_2}{2} + \dfrac{v_2 - v_1}{4} = 3$
>
> In matrix form:
> $$\begin{bmatrix} \tfrac{5}{12} & -\tfrac14 \\ -\tfrac14 & \tfrac34 \end{bmatrix}\begin{bmatrix} v_1 \\ v_2 \end{bmatrix} = \begin{bmatrix} 3 \\ 3 \end{bmatrix}$$
>
> Solving: $v_1 = 12$ V, $v_2 = 8$ V. The current from node 1 to node 2 is $(12-8)/4 = 1$ A.

## The conductance matrix by inspection

For circuits with only resistors and *independent current sources*, the matrix $\mathbf{G}\mathbf{v} = \mathbf{i}$ can be written without deriving anything:

- **Diagonal** $G_{kk}$: sum of all conductances connected to node $k$.
- **Off-diagonal** $G_{kj}$: *negative* of the total conductance directly between nodes $k$ and $j$.
- **Right side** $i_k$: net source current *entering* node $k$.

The matrix is symmetric. (Dependent sources break the symmetry — you then write KCL the long way.)

## Voltage sources and supernodes

A voltage source between a node and ground simply *fixes* that node voltage — one fewer unknown.

A voltage source between two non-reference nodes is trickier: you cannot write its current with Ohm's law. Instead, enclose both nodes and the source in a **supernode**:

1. Write **one** KCL equation for the closed surface around both nodes.
2. Add the **constraint equation** from the source: $v_a - v_b = V_s$.

```circuit
I 0,2 0,0 "10 A"
W 0,0 2,0
R 2,0 2,2 "2 Ω"
V 2,0 4,0 "5 V"
R 4,0 4,2 "3 Ω"
W 0,2 2,2
W 2,2 4,2
GND 3,2
TEXT 1.85,-0.32 v_1 anchor=end
TEXT 4.15,-0.32 v_2 anchor=start
LINE 1.45,-0.8 4.55,-0.8 dash color=anno
LINE 4.55,-0.8 4.55,0.5 dash color=anno
LINE 4.55,0.5 1.45,0.5 dash color=anno
LINE 1.45,0.5 1.45,-0.8 dash color=anno
TEXT 3,-1.05 supernode color=anno size=13
caption: The dashed surface encloses both nodes and the voltage source. Write one KCL equation for the whole surface.
```

> **Example.** A 5 V source connects node 1 ($+$) to node 2. Node 1 has 2 Ω to ground, node 2 has 3 Ω to ground, and a 10 A source injects into node 1.
>
> Supernode KCL: $\dfrac{v_1}{2} + \dfrac{v_2}{3} = 10$. Constraint: $v_1 - v_2 = 5$.
>
> Substituting $v_1 = v_2 + 5$: $3(v_2+5) + 2v_2 = 60 \Rightarrow v_2 = 9$ V, $v_1 = 14$ V.

## Dependent sources

Write the KCL equations as usual, treating the dependent source like an independent one, then add one equation expressing the controlling variable in terms of node voltages.

```quiz
? A circuit has 5 nodes including ground and no voltage sources. How many nodal equations must you solve?

```

```quiz
= 0.3 | 0.01 | S
> $G_{11} = 1/10 + 1/5 = 0.3$ S.
```

```quiz
? In the supernode example, how much current (A) flows through the 2 Ω resistor?
= 7 | 0.01 | A
> $v_1/2 = 14/2 = 7$ A. Check: the 3 Ω carries 3 A, and $7 + 3 = 10$ A. ✓
```

## Key takeaways

- Unknowns are node voltages; write KCL at every non-reference node.
- Resistor current from $a$ to $b$: $(v_a - v_b)/R$.
- Voltage source between two nodes → supernode KCL + constraint equation.
- Resistive circuits with current sources give a symmetric conductance matrix you can write by inspection.
