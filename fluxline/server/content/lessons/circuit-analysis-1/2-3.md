## Why simulate?

Hand analysis builds understanding; simulation builds confidence. Every professional circuit is simulated before it is built, because real designs have hundreds of components, nonlinear devices, and parasitic effects that no one solves by hand. **SPICE** (Simulation Program with Integrated Circuit Emphasis, Berkeley, 1973) is the ancestor of nearly every circuit simulator. Free versions you can install today:

- **LTspice** (Analog Devices): the most popular free schematic-based SPICE.
- **ngspice**: open source, scriptable, used inside KiCad.
- **Falstad Circuit Simulator**: runs in a browser, great for intuition (not SPICE, but similar).

## How SPICE solves a circuit

SPICE uses **modified nodal analysis (MNA)**, which is the nodal analysis you just learned plus one extra unknown for the current through each voltage source (since that current can't be written with Ohm's law). For $n$ non-ground nodes and $m$ voltage sources it solves an $(n + m)$-unknown linear system:

$$
\begin{bmatrix} \mathbf G & \mathbf B \\ \mathbf B^\top & \mathbf 0 \end{bmatrix}
\begin{bmatrix} \mathbf v \\ \mathbf i_V \end{bmatrix}
=
\begin{bmatrix} \mathbf i_S \\ \mathbf v_S \end{bmatrix}
$$

$\mathbf G$ is the conductance matrix you build by inspection; $\mathbf B$ marks which nodes each voltage source connects. Nonlinear devices (diodes, transistors) are handled by repeatedly linearizing them and re-solving (Newton–Raphson), and time-domain analysis repeats this at every time step.

## The netlist

Under every schematic is a text **netlist**: one line per element, listing its name, the nodes it connects, and its value. **Node 0 is always ground.** The first letter of the name sets the element type.

| Line | Meaning |
|---|---|
| `R1 1 2 4.7k` | resistor between nodes 1 and 2 |
| `C1 3 0 10u` | capacitor from node 3 to ground |
| `L1 2 3 1m` | inductor |
| `V1 1 0 DC 12` | 12 V source, $+$ at node 1 |
| `I1 0 1 DC 3` | 3 A source; current flows **from node 0 through the source into node 1** |
| `E1 4 0 1 2 100` | VCVS: $v_4 = 100\,(v_1 - v_2)$ |
| `G1 4 0 1 2 0.01` | VCCS: 0.01 S times $(v_1 - v_2)$ |

## Analyses

| Command | What it computes |
|---|---|
| `.op` | DC operating point: every node voltage and source current |
| `.dc V1 0 10 0.1` | repeats `.op` while sweeping V1 from 0 to 10 V |
| `.tran 1u 5m` | time-domain response, 1 µs steps to 5 ms (switching, transients) |
| `.ac dec 20 1 1meg` | small-signal frequency response, 20 points per decade |

## Traps that catch everyone

- **`M` means milli, not mega.** `1M` is 1 mΩ; one megohm is `1meg`. SPICE also ignores letters after a valid suffix, so `10kohm` is fine but `10Mohm` is 10 mΩ.
- **Floating nodes.** Every node needs a DC path to ground. A node connected only through capacitors makes $\mathbf G$ singular ("singular matrix" or "no DC path to ground"). Fix it with a very large resistor (e.g. 1 GΩ) to ground.
- **Loops of voltage sources or inductors**, which are physically contradictory in ideal form. Add a small series resistance.
- **Current-controlled sources** (`F`, `H`) sense the current through a named voltage source; add a 0 V source in series with the branch you want to measure.

## Practice

```quiz
? How many unknowns does modified nodal analysis solve for a circuit with 4 non-ground nodes and 2 independent voltage sources?
= 6 | 0 |
> One per node voltage plus one per voltage-source current: $4 + 2 = 6$.
```

```quiz
? A netlist contains `V1 1 0 DC 9`, `R1 1 2 1k`, `R2 2 0 2k`, `.op`. What is V(2)?
= 6 | 0.001 | V
> A voltage divider: $9 \cdot \frac{2k}{1k + 2k} = 6$ V.
```

```quiz
? You type `R5 3 4 4.7M` intending 4.7 megohms. What resistance does SPICE use?
- 4.7 MΩ
+ 4.7 mΩ
- 4.7 Ω
- an error is reported
> In SPICE, `M` (any case) means milli. Use `4.7meg`.
```

```quiz
? A simulation fails with "singular matrix." Which is the most likely cause?
- A resistor value of 0.1 Ω
+ A node connected to the rest of the circuit only through a capacitor
- Using `.tran` instead of `.op`
- A current source in parallel with a resistor
> In DC, capacitors are open circuits, so that node has no DC path to ground and its voltage is undefined.
```

```quiz
? In the line `I1 0 5 DC 2m`, which way does the 2 mA flow?
+ From node 0 through the source into node 5
- From node 5 through the source into node 0
- It depends on the rest of the circuit
- Into both nodes
> SPICE current sources push current from the first node, through the source, to the second node, i.e. into node 5.
```

## Key takeaways

- SPICE uses modified nodal analysis: node voltages plus voltage-source currents.
- A netlist lists element, nodes, value; node 0 is ground.
- `.op`, `.dc`, `.tran`, `.ac` are the four core analyses.
- Watch for `M` = milli, floating nodes, and source loops.
