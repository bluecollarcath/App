## Op-amp circuits are modular

Because an ideal op-amp's output has zero output resistance, an op-amp stage delivers the same output voltage no matter what it drives. That means stages can be **cascaded** with no loading: the total gain is just the product of the stage gains. This lesson builds the standard blocks you'll combine into real designs.

## The summing amplifier

Add more inputs to an inverting amplifier. The inverting input is still a virtual ground, so each input current is independent of the others:

```circuit
T 0,-0.2 v_1
R 0,-0.2 2.4,-0.2 R_1
T 0,0.5 v_2
R 0,0.5 2.4,0.5 R_2
W 2.4,-0.2 2.4,0.5
W 2.4,0.5 3,0.5
W 2.4,-0.2 2.4,-1.1
R 2.4,-1.1 5,-1.1 R_f
W 5,-1.1 5,1
OA 4,1
W 3,1.5 2.7,1.5
W 2.7,1.5 2.7,2
GND 2.7,2
W 5,1 6,1
T 6,1 v_o
caption: An inverting summer. Each input contributes current $v_k/R_k$ to the virtual-ground node.
```

KCL at the inverting input:

$$
\frac{v_1}{R_1} + \frac{v_2}{R_2} + \frac{v_o}{R_f} = 0
\quad\Rightarrow\quad
\boxed{v_o = -R_f\left(\frac{v_1}{R_1} + \frac{v_2}{R_2} + \cdots\right)}
$$

With all resistors equal, $v_o = -(v_1 + v_2 + \cdots)$: an analog adder. Unequal resistors give a **weighted** sum, which is how a simple digital-to-analog converter (DAC) works: weights of 1, 2, 4, 8 from binary-weighted resistors.

> **Worked example.** $R_f = 10$ kΩ, $R_1 = 10$ kΩ, $R_2 = 5$ kΩ, $v_1 = 1$ V, $v_2 = 0.5$ V.
> $v_o = -10\text{k}\left(\frac{1}{10\text{k}} + \frac{0.5}{5\text{k}}\right) = -(1 + 1) = -2$ V.

## The difference amplifier

Amplify the *difference* between two signals while rejecting what they have in common:

```circuit
T 0,0.5 v_1
R 0,0.5 2.4,0.5 R_1
W 2.4,0.5 3,0.5
W 2.4,0.5 2.4,-0.6
R 2.4,-0.6 5,-0.6 R_2
W 5,-0.6 5,1
OA 4,1
T 0,1.5 v_2
R 0,1.5 2.4,1.5 R_1
W 2.4,1.5 3,1.5
R 2.4,1.5 2.4,2.7 R_2 side=-1
GND 2.4,2.7
W 5,1 6,1
T 6,1 v_o
caption: The difference amplifier. The two $R_1$ resistors must match, and so must the two $R_2$ resistors.
```

The non-inverting input sits at $v_+ = v_2\frac{R_2}{R_1+R_2}$. KCL at the inverting input with $v_- = v_+$:

$$
\frac{v_1 - v_+}{R_1} = \frac{v_+ - v_o}{R_2}
\quad\Rightarrow\quad
\boxed{v_o = \frac{R_2}{R_1}\,(v_2 - v_1)}
$$

If $v_1 = v_2$ (a **common-mode** signal, such as noise picked up equally on both wires), the output is zero. In practice resistor mismatch lets some common-mode signal through; the **common-mode rejection ratio (CMRR)** measures how well it's rejected. With 1% resistors and a gain of 1, CMRR can be as poor as about 34 dB, which is why precision applications use **instrumentation amplifiers** with laser-trimmed resistors.

## Cascading stages

Because an ideal op-amp's output isn't affected by its load:

$$
A_{total} = A_1 A_2 \cdots A_n
$$

> **Example.** A non-inverting stage with gain 5 drives an inverting stage with gain $-2$. Total gain $= -10$. A 50 mV input gives $-0.5$ V.

## A preview: integrators and differentiators

Replace $R_f$ in the inverting amplifier with a capacitor $C$. The feedback current $C\,dv_o/dt$ must equal $v_i/R$, so

$$
v_o(t) = -\frac{1}{RC}\int v_i\,dt
$$

That's an **integrator**, used in analog computers, PID controllers, and waveform generators. You'll have the tools to analyze it fully after Unit 5.

```quiz
? A summing amplifier has $R_f = 20$ kΩ, $R_1 = 10$ kΩ, $R_2 = 20$ kΩ, with $v_1 = 0.5$ V and $v_2 = -1$ V. What is $v_o$?
= 0 | 0.001 | V
> $v_o = -20\text{k}\left(\frac{0.5}{10\text{k}} + \frac{-1}{20\text{k}}\right) = -(1 - 1) = 0$ V.
```

```quiz
? A difference amplifier has $R_1 = 10$ kΩ and $R_2 = 50$ kΩ. With $v_2 = 1.2$ V and $v_1 = 1.0$ V, what is $v_o$?
= 1 | 0.001 | V
> $\frac{R_2}{R_1}(v_2 - v_1) = 5 \times 0.2 = 1$ V.
```

```quiz
? For the same difference amplifier, what is $v_o$ when $v_1 = v_2 = 3$ V (ideal, matched resistors)?
= 0 | 0.001 | V
> A pure common-mode input produces zero output when resistors match perfectly.
```

```quiz
? Three ideal op-amp stages with gains 4, −2.5, and 3 are cascaded. What is the overall gain?
= -30 | 0.001 |
> $4 \times (-2.5) \times 3 = -30$. Ideal stages don't load each other.
```

```quiz
? A 4-bit binary-weighted DAC uses an inverting summer. If the most significant bit's resistor is $R$, what is the least significant bit's resistor?
- $R$
- $2R$
- $4R$
+ $8R$
> Weights 8, 4, 2, 1 need resistors $R, 2R, 4R, 8R$: smaller weight means larger resistor.
```

## Key takeaways

- Summer: $v_o = -R_f\sum v_k/R_k$.
- Difference amp: $v_o = (R_2/R_1)(v_2 - v_1)$ with matched resistors; CMRR depends on matching.
- Ideal stages cascade by multiplying gains.
- A capacitor in the feedback path makes an integrator.
